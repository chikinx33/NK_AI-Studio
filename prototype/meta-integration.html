내 계정의 Instagram·Threads 연결

연결부터 게시까지

NK Studio는 로그인한 이용자별로 SNS 연결을 저장합니다. 고객은 본인의 SNS 계정으로 동의하며 운영자의 Meta 관리자 계정을 사용할 필요가 없습니다. Instagram은 비즈니스 또는 크리에이터 계정이 필요합니다.

  1. SNS 연결 설정에서 연결할 플랫폼을 선택합니다.
  2. 플랫폼 인증 화면에서 본인 계정과 요청 권한을 확인하고 동의합니다.
  3. NK Studio로 돌아오면 서버 저장 확인 결과와 연결된 사용자명을 확인합니다. 초대·동의·저장 완료는 서로 다른 단계입니다.
  4. 브랜드 스튜디오 또는 퍼블리싱 화면에서 콘텐츠와 게시 계정을 확인한 뒤 즉시 게시하거나 예약합니다. 게시 성공 여부와 플랫폼 게시물 ID를 확인합니다.

개발자 역할 부족·앱 접근 제한 오류는 NK Studio 운영자가 앱 공개와 권한 심사를 해결해야 합니다. 브라우저 프로필 변경, 고객의 개발자 등록, 테스터 추가는 정식 공개 연결의 대안이 아닙니다.

Reviewer and customer guide

Sign in to your own NK Studio login, open SNS Connections, and connect your own Instagram professional account or Threads account. Review the platform consent screen. Return to NK Studio and verify the saved account name. Select content and its destination account before publishing or scheduling. Inspect the returned published status and remote post ID. Connection status is not proof of publication.

Basic permissions identify the user's profile and posts. Content publishing permissions post content approved by that user. Insights permissions retrieve that user's post performance. Tokens are handled by the server and never returned to the browser. Project sharing does not allow changing the owner's connections; publishing with the owner's connection requires an explicit project editor grant.

Customers do not need an operator's Meta account, developer roles or manual tester enrollment for the intended public service. Public availability requires Meta app publication and approval of the necessary permissions. See data deletion for disconnect and deletion requests.
