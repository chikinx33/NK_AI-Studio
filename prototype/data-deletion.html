SNS 연결 해제와 데이터 삭제

  1. 본인의 NK Studio 계정으로 로그인한 후 SNS 연결 설정에서 Instagram 또는 Threads의 ‘연결 해제’를 선택하세요. 해당 NK Studio 사용자의 저장된 토큰·계정 연결 정보가 삭제되며 새 게시와 예약 실행은 이 연결을 사용할 수 없습니다.
  2. SNS 플랫폼의 앱 권한까지 철회하려면 Instagram 또는 Threads의 설정에서 NK Studio의 접근 권한을 제거하세요. Meta의 앱 권한은 SNS 계정 기준이므로 같은 SNS 계정을 연결한 다른 NK Studio 로그인에도 영향을 줄 수 있습니다.
  3. 성과 보고서 등 이미 보관된 플랫폼 데이터의 삭제도 원하시면 가입 이메일로 chikinx1@gmail.com에 요청해 주세요. NK Studio 사용자명, 대상 플랫폼·SNS 사용자명, 삭제 범위를 적어 주세요. 비밀번호·토큰·인증 코드는 보내지 마세요. 본인 확인 후 7일 이내 처리 결과를 안내합니다.
  4. NK Studio 계정 전체를 삭제하려면 계정 설정의 탈퇴 절차를 이용하거나 같은 이메일로 요청해 주세요. 탈퇴 대기·법정 보존 대상은 개인정보처리방침을 따릅니다.

이미 SNS에 게시한 콘텐츠는 NK Studio 연결 해제로 삭제되지 않습니다. 해당 SNS에서 직접 관리해 주세요.

Meta에서 데이터 삭제 요청 후 이 페이지로 오셨다면 발급된 확인 코드를 보관해 주세요. 연결 자격증명 제거와 전체 보관 데이터 삭제 완료는 별도 단계이며, 이 페이지가 표시되는 것만으로 삭제 완료를 뜻하지 않습니다. 처리 상태는 확인 코드와 함께 지원 이메일로 문의해 주세요.

Disconnect and request deletion

  1. Sign in to your own NK Studio account. Open SNS Connections and disconnect Instagram or Threads. Stored credentials and connection details for that NK Studio login are removed. Future publishing and scheduled jobs cannot use the disconnected credential.
  2. To revoke the platform app grant as well, remove NK Studio in Instagram or Threads settings. Meta grants belong to the SNS account and may also affect other NK Studio logins connected to that same SNS account.
  3. For deletion of retained platform data such as reports, email chikinx1@gmail.com from your registered email. Include your NK Studio username, platform, SNS username and requested scope. Never send passwords, tokens or verification codes. We verify ownership and respond within 7 days.
  4. For full NK Studio account deletion, use account settings or contact the same email. Applicable deletion grace periods and legally retained records are described in our Privacy Policy.

Previously published SNS posts remain on that platform. A Meta deletion confirmation code is a request receipt; opening this page does not certify deletion of all retained data. Contact support with your code for processing status.
