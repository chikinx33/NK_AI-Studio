# NK AI Studio 소개 영상

NK AI Studio의 `개요 → 시나리오 → 생성 → 편집 → MP4` 흐름을 소개하는 30초짜리 Remotion 영상입니다.

## 미리보기

```bash
npm run dev
```

## 대표 프레임

```bash
npm run still
```

## MP4 렌더

```bash
npm run render
```

결과 파일은 `out/nk-studio-intro.mp4`에 생성됩니다.

Windows에서 Remotion 네이티브 인코더가 종료되더라도, 렌더 스크립트가 완성된 프레임 캐시를 감지해 번들 FFmpeg로 MP4를 마무리합니다.
