# 사용자별 텍스트·이미지 생성 설정과 전수조사

랜딩페이지 `구독·API 설정`에서 AI 채팅과 이미지 생성에 본인 계정 사용 여부를 각각 체크하고 저장합니다. 체크 해제 시 기존 마스터 자격 증명과 크레딧 경로를 사용합니다. 체크 시 로그인 사용자에게 저장된 자격 증명만 사용하며 연결 누락·만료·오프라인·사용 한도 오류를 마스터 과금으로 넘기지 않습니다.

AI 채팅에는 Claude 구독 토큰 또는 Anthropic API 키를 입력합니다. 이미지에는 ChatGPT 구독 로그인 연결 또는 OpenAI API 키를 선택합니다. ChatGPT 구독은 API 키 입력이 필요하지 않습니다. 기존 연결 프로그램과 사용자의 PC 인증 프로필을 사용하며 PC가 실행 중이어야 합니다. 본인 OpenAI API 키는 해당 API 계정으로 별도 과금됩니다.

기존 본인 인증 등록 계정은 선택을 유지합니다. 새 계정의 두 체크박스는 기본 해제입니다. 체크 해제로 기존 키를 삭제하지 않습니다. 계정 변경 시 입력 중인 키를 지우며 응답에는 비밀값 대신 등록 여부만 반환합니다.

## 이미지 생성 경로 조사 결과

2026-09-17 실제 공급자 호출과 프론트엔드·에이전트 호출부를 함께 조사했습니다. 이미지 공급자 호출은 `/api/imagen`과 `/api/upscale`에 모입니다. 이 두 서버 진입점에서 사용자별 인증을 강제하므로 화면의 provider 값이나 이전 계정의 브라우저 모델 선택으로 과금 주체를 바꿀 수 없습니다.

## 구현과 과금

- `app_settings.user_chat_enabled`, `user_image_enabled`에 사용자 선택을 저장합니다. 새 행의 기본값은 false이며 기존 행의 NULL은 이전 본인 등록 상태를 보존합니다. 명시적인 false가 항상 우선합니다. 만료된 연결도 본인 설정을 유지하고 오류를 표시합니다.
- 본인 채팅 설정은 Claude 텍스트 생성 전체와 AI 기업 에이전트에 적용됩니다. 에이전트에 GPT/Atlas 모델을 지정해도 본인 Claude 인증을 사용합니다.
- 본인 이미지 API 경로는 사용자 OpenAI 키만 생성에 사용하고 Gemini·Atlas 생성 키를 제거합니다. GCS 서비스 계정은 저장·참고 이미지 읽기용입니다. 다른 생성 공급자로 폴백하지 않습니다.
- 본인 이미지 경로는 NK 이미지 크레딧을 예약·차감하지 않습니다. 이미지 견적에 NK 크레딧 0과 실제 본인 구독/API 과금 경로를 표시합니다. 영상 파이프라인도 본인 스틸분을 NK 크레딧 견적에서 제외합니다.
- 웹 이미지 호출은 서버의 202 응답을 받은 경우 같은 구독 작업을 조회합니다. AI 기업 도구는 큐 접수를 완료로 표시하지 않고 잡에 큐 ID·요청 해시·기존 결과를 저장합니다. 결과가 저장되면 작업/메시지 조회에서 이어가며 이전 이미지를 재생성하지 않습니다.
- 완료·실패 메시지는 사용자·대화별 백그라운드 이벤트로 저장하고 순번 커서로 채팅에 전달합니다. 대화 전환 시 커서를 복원하며 재조회로 같은 완료 메시지를 반복 표시하지 않습니다. 전체 대화 이력을 매번 폴링하지 않습니다.
- 승인 실행과 영상 제작 배치도 동일한 대기·재개 처리를 사용합니다. 승인된 작업의 승인 상태와 업무 파일 등록을 유지하며 DB 실행권으로 중복 승인을 차단합니다.
- 에이전트의 같은 이미지 요청은 결정적인 요청 ID를 사용합니다. 여러 이미지는 큐에 접수하고 소유자당 하나씩 실행합니다. 체크 해제 또는 API 방식 전환 시 아직 시작하지 않은 큐 작업을 취소합니다. 실행 중인 결과는 원래 소유자에게 저장합니다.
- 참고 이미지·카메라·마스크·이전 수정 지시를 전달합니다. 생성 모델의 결과이므로 전용 업스케일러의 정확한 배율이나 마스크 밖 픽셀의 완전한 일치를 보장하지 않습니다. 이를 이유로 다른 공급자를 몰래 호출하지 않습니다.

## 검증

`prototype/tests/generation-account-routing.test.mjs`에서 독립 체크·해제·키 보존·계정 격리·미등록 차단·서버 선택 우선·API 키 격리·일반/승인 에이전트 재개·동시 조회의 단일 완료·중복 승인 차단·만료된 연결·GPT/Atlas 채팅 모델 지정·영상 제작 스틸 재개를 실제 함수 실행으로 검증합니다. 기존 연결 프로그램 테스트는 서버 선택 후 큐 조회와 배치 직렬 실행을 검증합니다.
