## 2. 촬영 전 세팅 — 이 3개를 안 하면 또 반려된다 ★★★

### 2-1. 녹화 범위를 "화면 전체"로 바꾼다 ← 이번 반려의 핵심
지난번 설정은 브라우저 안쪽만 찍혔다. 주소창이 반드시 프레임에 들어와야 한다.

- **Bandicam을 계속 쓴다면:** 상단 모드를 **`화면 녹화` → `전체 화면(Fullscreen)`** 으로 바꾼다.
  (`사각형 지정 영역`이나 `창 선택` 모드면 또 잘린다)
- **또는 OBS Studio (무료, 워터마크 없음):** 소스에 **`디스플레이 캡처(Display Capture)`** 추가.
- **또는 Windows 게임바 `Win + G`** (무료, 워터마크 없음).

> 어떤 툴을 쓰든, **찍고 나서 파일을 열어 주소창이 보이는지 직접 확인**한다. 이게 마지막 관문이다.

### 2-2. 워터마크를 없앤다
현재 영상 상단 중앙에 `www.BANDICAM.com` 이 크게 박혀 있다. 무료판 워터마크다.
**하필 주소창이 있어야 할 자리를 덮는다.** 둘 중 하나로 해결한다.

- Bandicam을 정식 등록해 워터마크를 끈다, **또는**
- 워터마크가 없는 OBS Studio / Windows 게임바(`Win + G`)로 바꾼다 ← 추천(무료)

### 2-3. Chrome 주소창에 `https://` 를 표시시킨다 (보험)
주소창 자체는 원래 늘 떠 있었다. 다만 **Chrome이 기본값으로 `https://` 를 잘라낸다.**
2026-08-07 NK가 보내준 브라우저 스크린샷에서도 주소창이 `drive.google.com/drive/u/0/...` 로
표시되고 **`https://` 가 없다** — 지금 설정이 그 상태다.

심사관이 쓴 표현은 "**the full Website url**"이다. 도메인+경로만으로도 통과할 수 있지만,
`https://` 까지 찍혀 있으면 해석의 여지가 사라진다. 어차피 다시 찍는 김에 켜 두는 게 안전하다.

1. Chrome 주소창의 URL 위에서 **마우스 오른쪽 클릭**
2. **`전체 URL 항상 표시`** (영문: `Always show full URLs`) 클릭 → 체크됨
3. 주소창이 `https://nkstudio.org/...` 로 바뀐 걸 눈으로 확인하고 촬영 시작

### 2-4. 그 밖의 준비
- **전체화면(F11) 금지.** 주소창이 사라진다. 브라우저 창은 **최대화**.
- `https://nkstudio.org/app` 에 **미리 로그인**해 둔다.
- 다른 탭은 모두 닫는다.
- ★**북마크바를 숨긴다 (`Ctrl + Shift + B`).** 현재 북마크바에 `정부기관`·`Bank.tax`·`Outsourcing` 등
  개인/업무 폴더명이 그대로 노출된다. 심사 사유는 아니지만 외부인에게 보낼 영상에 남길 이유가 없다.
- 해상도 1920×1080 권장. 주소창 글씨가 흐리면 심사관이 못 읽는다.

## 3. 공통 규칙

1. 마우스를 **천천히** 움직인다.
2. 중요한 화면에서 **2초 멈춘다.**
3. 파일은 **mp4, 50MB 이하**, 최대 5개.
4. ★**세 영상 전부, 시작 5초 안에 주소창의 `https://nkstudio.org/...` 를 보여준다.**
5. ★영상 도중 모달이 화면을 덮어도 **주소창은 계속 화면에 남아 있어야 한다.**

# 영상 2 — 게시하기 (약 100초) ★가장 중요★

**목적:** 게시 전에 사용자가 직접 선택하는 화면이 있다 (`video.publish`)

> ⚠️ 지난 영상은 앱 화면부터 시작해 **주소창이 한 번도 안 나왔다.** 반드시 0번부터 시작한다.
> 2번 이후 동작은 **지난번과 똑같이** 하면 된다 — 내용은 이미 요건을 충족했다.

| 순서 | 할 일 |
|---|---|
| 0 | ★**주소창을 비우고 `https://nkstudio.org/brand` 를 손으로 타이핑**한다. Enter |
| 1 | ★**마우스를 주소창 위에 올리고 3초 멈춘다** ★★★ |
| 2 | **모양새 친구들**의 `Open brand` 클릭 |
| 3 | ★주소가 바뀌면 **주소창을 다시 2초 보여준다** |
| 4 | 에피소드 **숨바꼭질**(또는 아무 에피소드) 클릭 → `SNS Setup` → `04 — Publish` |
| 5 | TikTok 줄의 **Deploy** 클릭 → 창이 뜨는 데 5~10초 걸린다. **기다린다** |
| 6 | 창이 다 뜨면 **아무것도 안 만지고 3초 멈춤** ★★★ (기본값이 없다는 증거) |
| 7 | `Post to TikTok` 버튼을 **한 번 눌러봄** → 안 눌림. **2초 멈춤** |
| 8 | `Only you` 클릭 |
| 9 | `Comment` 체크 |
| 10 | `Disclose video content` 켜기 → 아래 항목 2개가 나오는 것 **2초 멈춤** |
| 11 | `Your brand` 체크 → 회색 안내문이 뜨는 것 **2초 멈춤** |
| 12 | 맨 아래 파란 링크 두 개 위에 마우스 올리고 **2초 멈춤** |
| 13 | `Post to TikTok` 클릭 |
| 14 | "TikTok is processing your post." → 완료까지 **끝까지 보여줌** |

### 6번이 왜 제일 중요한가
창이 처음 열렸을 때 **아무것도 선택돼 있지 않은 상태**가 이 영상의 핵심 증거다.
심사관이 확인하려는 건 "앱이 몰래 기본값을 정해두지 않았는가"다.

### 하지 말 것
`Branded content`는 체크하지 않는다. 체크하면 `Only you`가 잠겨서 게시가 안 된다.
