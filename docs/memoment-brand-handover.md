# Memoment 브랜드 인수인계 — 코어(Core) 실행 지시서

작성: Cowork(Memoment 프로젝트) · 2026-07-31 · 수신: **코어 Core (L1 총괄)**
목적: **Memoment를 브랜드 허브에 등록하고, 숏폼 콘텐츠 프로젝트 카드를 생성한다.**

이 문서 하나로 충분하다. Memoment 저장소를 읽지 않아도 된다 — 필요한 사실은 전부 아래에 있다.

---

## 0. 코어가 실행할 것 (요약)

1. **`brand_save` 1회** — §3의 JSON으로 브랜드 코어 생성/갱신 (`brandId: "memoment"`)
2. **`project_create` 1회** — §5의 EP1만 만든다 (`projectId: "memoment-ep1"`)
3. **`project_add_episode` 5회** — EP2~EP6을 EP1에 붙인다 (`parentProjectId: "memoment-ep1"`)
4. 이후 마키(캠페인) → 플롯(기획) → 잉크·픽셀·비트(제작) → 리치(발행) 순으로 위임

### 🔴 project_create 를 여러 번 부르지 말 것

**에피소드는 `project_create` 가 아니라 `project_add_episode` 로 만든다.**
`project_add_episode` 만 부모의 브랜드 맥락(`brandVoice` `brandRules` `bannedExpressions` `worldSetting` `brandStory` `brandKeywords` 등)을 **상속**한다. `project_create` 를 6번 부르면 6개 카드가 **브랜드 맥락 없이 각각 따로 노는 프로젝트**가 된다.

> `brand_save`·`project_create`·`project_add_episode` 는 전부 `gate:true` 다. 승인 요청 시 **무엇을 어떤 값으로 쓰는지** 명시할 것.

## 1. 이 제품이 왜 존재하는가 (가장 중요 — 모든 카피의 뿌리)

**만든 사람이 직접 절실해서 만들었다.** 시장 조사로 도출한 기능이 아니다. 이 사실이 모든 문안의 가장 강한 근거이며, 콘텐츠에서 이 톤을 잃지 말 것.

해결한 불편은 **"흩어짐"** 하나이고, 두 갈래로 나타난다.

| 불편 | 기존 상황 | Memoment의 해결 |
| --- | --- | --- |
| **메모가 흩어진다** | 스티키 메모는 메모 1개 = 카드 1개. 쓰다 보면 수십 장이 널브러지고 관련된 것끼리 모아 보려면 눈으로 찾아야 한다 | **라벨을 지정하면 그 라벨이 곧 하나의 메모장**이 된다. 흩어진 걸 나중에 모으는 게 아니라 애초에 한 곳에서 관리된다 |
| **앱이 흩어진다** | 어떤 건 체크해서 끝내야 하고 어떤 건 그냥 적어두는 것인데, 그러려고 앱을 두 개 쓰면 또 흩어진다 | **라벨마다 투두 모드 ↔ 일반 메모 모드를 전환**한다. 같은 앱 같은 자리에서 이 라벨은 할 일 목록, 저 라벨은 그냥 기록 |

## 2. 강점과 강조 순위 (이 순서를 바꾸지 말 것)

| 순위 | 강점 | 설명 |
| --- | --- | --- |
| **1** | **라벨로 흩어진 메모를 하나의 메모장으로** | 제품의 출발점 |
| **1** | **라벨마다 투두 ↔ 일반 메모 모드 전환** | 위와 한 쌍 |
| 2 | **체크 3단계** | 체크 1번 = 당장 할 일 / 체크 2번 = 완료 / 휴지통 = 완료된 것 정리. **그룹 제목을 누르면 하위 항목까지 함께** 순환 |
| 3 | **완료 캘린더** | 휴지통으로 치운 완료 항목이 사라지지 않고 **날짜별 기록으로 쌓인다.** 완료 안 한 것을 지우는 건 기록되지 않는다(할 일을 끝낸 기록이지 삭제 로그가 아니다) |
| 보조 | 열자마자 바로 입력(모달 없음) · 오프라인 동작 · 실행취소 · 빠른 검색 · 아이콘 라벨 | |

### 🔴 금지

- **"항상 위(always on top)"를 차별점으로 내세우지 말 것.** 다른 메모 앱에도 흔한 기능이며, MS Store에 `AlwaysMemo App(항상 맨 앞)` 같은 경쟁 앱이 이미 있다. 기능 목록에 넣는 건 무방하나 **후크·헤드라인으로 쓰지 말 것.**
- 없는 기능을 말하지 말 것. **macOS·iOS·Android 네이티브 앱은 없다.**
- **무료/유료 경계를 흐리는 문구 금지.** 과거 MS Store 인증이 이 사유(정책 10.8.4, 무료/Pro 문안 모순)로 반려된 적이 있다.

## 5. 프로젝트 카드 — 시리즈 1개 + 에피소드 6개

콘텐츠 형식은 **숏폼 1개 = 강점 1개**다. 긴 소개 영상 하나로 만들지 말 것. 6개 채널에 같은 소재를 형식만 바꿔 돌린다.

### 5-1. 먼저 `project_create` 1회 (EP1)

```json
{
  "projectId": "memoment-ep1",
  "seriesId": "memoment",
  "seriesTitle": "Memoment",
  "episodeTitle": "EP1 흩어진 메모를 라벨 하나로",
  "projectType": "숏폼",
  "brandSummary": "흩어지는 메모를 라벨 하나로 묶고, 같은 메모장을 투두 ↔ 일반 메모로 전환해 쓰는 로컬 우선 스티키 메모 앱.",
  "coreMessage": "메모는 흩어지고, 앱은 갈라진다. Memoment는 라벨 하나로 그 둘을 한 곳에 묶는다."
}
```

> `seriesId` 를 `memoment` 로 주면 `payload.brandId` 가 같은 값으로 설정되어 §3에서 만든 브랜드와 연결된다.

### 5-2. 그다음 `project_add_episode` 5회

`parentProjectId` 를 **`memoment-ep1`** 로 고정하고 `episodeTitle` 만 바꿔 5번 호출한다. `projectId` 는 지정하지 않으면 `memoment-ep2` … `memoment-ep6` 로 자동 부여된다.

| 회차 | episodeTitle | 보여줄 화면 | 우선순위 |
| --- | --- | --- | --- |
| 1 | (EP1 — 위에서 생성) **흩어진 메모를 라벨 하나로** | 여기저기 흩어진 메모 → 라벨 지정 → 하나의 메모장으로 정리되는 장면 | **1** |
| 2 | **EP2 같은 메모장, 투두 ↔ 일반 전환** | 버튼 하나로 체크박스가 생겼다 사라지는 장면 | **1** |
| 3 | **EP3 체크 1번은 오늘 할 일, 2번은 완료** | 3단계 순환. 그룹 제목을 누르면 하위 항목까지 한 번에 | 2 |
| 4 | **EP4 치운 게 사라지지 않는다** | 휴지통 → 완료 캘린더에 날짜별로 쌓이는 장면 | 3 |
| 5 | **EP5 열자마자 바로 입력** | 앱 열림 → 즉시 타이핑(모달 없음) | 보조 |
| 6 | **EP6 인터넷 없이도** | 오프라인에서 작성·완료 | 보조 |

**EP1·EP2가 제품의 이유 그 자체다. 이 둘을 먼저 완성한다.**

### 5-3. 이미 잘못 만들어진 카드가 있다면

이 문서의 이전 판을 따라 **여러 개의 독립 프로젝트**가 생성됐다면, `memoment-ep1` 하나만 남기고 나머지는 `project_delete` 로 정리한 뒤 5-2를 실행한다. (남겨두면 브랜드 맥락 없는 빈 카드가 목록을 어지럽힌다.)

## 6. 발행 시 지켜야 할 측정 규칙

콘텐츠 링크는 **반드시 캠페인 ID를 붙인 스토어 링크**를 쓴다. 안 붙이면 어느 콘텐츠가 설치를 만들었는지 구분되지 않는다.

```
https://apps.microsoft.com/detail/9PHP8NRHH165?cid=<채널>-<번호>
예: ?cid=yt-shorts-01  ?cid=ig-reels-01  ?cid=tiktok-01  ?cid=x-01  ?cid=threads-01  ?cid=fb-01
```

- 결과는 Microsoft Partner Center의 **"App page views and conversions by campaign ID"** 차트에서 캠페인별로 확인된다.
- 웹으로 보내는 링크(`memoment.nkstudio.org`)는 유입 사이트 단위까지만 구분된다.
- **웹 계측은 2026-08-07부터 수집이 시작된다.** 그전 발행은 웹 쪽 성과가 남지 않는다.

## 8. 아직 정해지지 않은 것 (지어내지 말 것)

**Pro에 돈을 낼 이유를 무엇으로 둘지 미확정이다.** 조사 결과 Microsoft Sticky Notes·Google Keep·Microsoft To Do·Simplenote·Standard Notes가 **전부 클라우드 동기화를 무료로 제공**한다. 즉 "동기화하려면 결제하세요"는 시장에서 약한 메시지다.

→ **콘텐츠에서 Pro 결제를 밀지 말 것.** 지금 단계의 목표는 **설치와 사용**이다. 가격은 물어보면 정확히 답하는 수준으로만 노출한다. 유료 근거 재정의는 NK 결정 사항이며 아직 열려 있다.
