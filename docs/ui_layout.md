# NK_Studio UI 기본 설계

## 디자인 방향
- Web-first PWA, 필요 시 동일 코드베이스로 Tauri 데스크톱 빌드.
- 톤&매너: 짙은 챠콜(#0F172A) 바탕, 선명한 오렌지(#FF7A00) + 틸(#0BBFA5) 듀얼 포인트. 플랫+살짝 입체감(카드 음영 4dp). 배경에 그라디언트 노이즈 혹은 라인 패턴으로 깊이감.
- 서체: "Space Grotesk" 또는 "General Sans"(대체: "Pretendard"), 1.05 line-height, 숫자는 탭 고정.
- 그리드: 12-col, 주요 브레이크포인트 1440 / 1200 / 1024 / 768 / 480.
- 인터랙션: 버튼/카드 호버에 1% scale + 살짝 밝기, 중요 작업은 토스트·progress bar로 피드백.

## 글로벌 프레임
- 좌측 사이드바(축소 가능): 로고, 핵심 플로우 메뉴, 자동화/큐 뱃지.
- 상단바: 프로젝트 선택, 검색(명령팔레트), 알림, 언어·테마 토글.
- 메인 캔버스: 선택된 기능에 맞는 2~3분할 레이아웃.
- 상태/프로그레스 바: 하단, 현재 렌더/업로드 진행률.

사이드바 계층 예시
```
NK_Studio
├ Dashboard
├ Research · Market
├ Script · Story
├ Media Lab (Image/Video/Audio)
├ Timeline · Edit
├ Voice & Subtitles
├ Automation Queue
└ Publish
```

## 화면별 러프 와이어프레임

### 1) Dashboard (파이프라인 허브)
- 상단 카드: "새 파이프라인", "자동화 레시피", "중단 지점에서 재개".
- 중앙: 진행 중 파이프라인 목록(단계 칩: 리서치, 대본, 생성, 편집, 렌더, 배포).
- 우측: 자동화 이벤트 로그 + 단계별 상태(스텝 바) + 크레딧/리소스 사용량.

```
┌──────── Dashboard ────────┐
│ [새 프로젝트][템플릿]    [최근 이어하기]
│───────────────────────────│
│ 진행 중 프로젝트 카드 2~3열 그리드                │
│───────────────────────────│
│ 우측 패널: 자동화 이벤트 / 단계 상태 / 사용량        │
└───────────────────────────┘
```

### 2) Research · Market
- 좌: 브리프/목표 입력, 키워드, 타겟.
- 중: SERP/뉴스 요약 카드 스택, 경쟁사 테이블.
- 우: 인사이트 노트(LLM 요약), 태스크 체크리스트.

### 3) Script · Story
- 듀얼 뷰: (a) 계층 아웃라인(씬/샷/비트) (b) 원고 에디터/보드.
- 상단: 톤/길이/플랫폼 프리셋 셀렉터.
- 우측: 컨텍스트 패널(캐릭터/장소/용어집), 버전 관리.

```
┌ 씬/섹션 리스트 ┬──────── 원고 에디터 ────────┬ 메모/컨텍스트 ┐
│ 드래그로 순서  │ 마크다운 + 코멘트, 버전 탭 │ 용어집/리뷰   │
└────────────────┴─────────────────────────────┴───────────────┘
```

### 4) Media Lab
- 탭: Image / Video / Audio.
- Image: 프롬프트 + 스타일 슬라이더 + 시드, 결과 갤러리(모자이크), 선택 시 우측 메타/리롤.
- Video: 텍스트→비디오, 참고 이미지/비디오 업로드, 길이/비율 선택, 썸네일 미리보기.
- Audio: TTS/더빙, 목소리 선택, 감정/말속도, 스크립트 라인별 미리듣기.

### 5) Timeline · Edit (핵심 작업 공간)
- 3분할: 좌(씬/에셋 브라우저), 중(미리보기 + 레이어 타임라인), 우(클립/장면 속성·이펙트·자막).
- 타임라인: 비디오/오디오/자막 트랙, 스냅/자석, 멀티셀렉트, 키프레임 패널 팝업.

```
┌──── 씬·에셋 ┬────────── 미리보기 ──────────┬ 속성 ─────┐
│ 스토리보드 │ [프리뷰 창][플레이 헤드]      │ 클립 설정 │
│ 에셋 검색   │───────────────────────────────│ 트랜지션 │
│ 즐겨찾기    │ 비디오/오디오/자막 트랙 타임라인│ 오디오 EQ │
└─────────────┴────────────────────────────────┴───────────┘
```

### 6) Voice & Subtitles
- 좌: 자동 전사 결과(타임코드), 라인별 수정/잠금.
- 우: 선택된 라인 프리뷰 + 음성 선택 + 피치/속도/감정.
- 하단: 자막 스타일 프리셋(폰트, 배경, 애니메이션) 실시간 반영.

### 7) Automation Queue & Publish
- 테이블: 파이프라인 이름, 현재 단계, 상태(대기/실행/완료/오류), ETA, 크레딧 예상.
- 우측: 플랫폼 프리셋(YouTube/Shorts/TikTok/Reels), 챕터·태그·썸네일 자동 채우기.
- 완료 후: 다운로드, 공유 링크, 재업로드, 재시도/다시 렌더 버튼.

### 8) Assets Library
- 그리드/리스트 토글, 필터(타입/날짜/프로젝트), 태그, 라이선스/출처 뱃지.
- 배치 작업: 삭제/이동/라벨/워터마크 제거(허용 범위 표시).

### 9) Settings
- 워크스페이스/팀, 결제·크레딧, 모델 선택(클라우드/로컬), 저장소/백업, 단축키 매핑.

## 반응형 가이드
- ≥1440: 3컬럼 가능(좌 패널 + 메인 + 우 패널).
- 1200~1024: 우측 속성 패널을 드로어로 전환.
- ≤768: 사이드바 아이콘화, 타임라인 단순화(클립 카드 리스트) + 필수 컨트롤만 떠있는 플로팅 바.

## 브랜드/시각 요소
- 버튼: 프라이머리(#FF7A00), 세컨더리(다크 바탕 + 틸 텍스트), 섀도우 y=6 blur=14.
- 아이콘: 라운드 코너, 2px 스트로크, 흰색/틸/오렌지 제한.
- 그래픽: 배경에 대각선 라인/노이즈 패턴, 카드 상단에 얇은 컬러 바(섹션 구분).

## 초기 온보딩 흐름
1) 프로젝트 생성 모달: 목적/플랫폼/길이/톤 선택 → 템플릿 추천.
2) 리서치 → 대본 → 미디어 생성 → 타임라인 → 더빙/자막 → 렌더 → 배포 순서로 상단 프로그레스 스텝.
3) 각 스텝에 "AI 제안" 버튼과 "수동 편집" 토글 병행.
