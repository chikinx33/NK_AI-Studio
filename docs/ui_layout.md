# NK_Studio UI 기본 설계

## 디자인 방향
- Web-first PWA, 필요 시 동일 코드베이스로 Tauri 데스크톱 빌드.
- 톤&매너: 짙은 챠콜(#0F172A) 바탕, 선명한 오렌지(#FF7A00) + 틸(#0BBFA5) 듀얼 포인트. 플랫+살짝 입체감(카드 음영 4dp). 배경에 그라디언트 노이즈 혹은 라인 패턴으로 깊이감.
- 서체: "Space Grotesk" 또는 "General Sans"(대체: "Pretendard"), 1.05 line-height, 숫자는 탭 고정.
- 그리드: 12-col, 주요 브레이크포인트 1440 / 1200 / 1024 / 768 / 480.
- 인터랙션: 버튼/카드 호버에 1% scale + 살짝 밝기, 중요 작업은 토스트·progress bar로 피드백.

## 글로벌 프레임 (1인·Scene 자동화 전용)
- 좌측 사이드바(축소 가능): 로고, 핵심 플로우 메뉴, 자동화 큐 뱃지. **협업/담당자/팀 메뉴 없음.**
- 상단바: 파이프라인 선택(또는 새 파이프라인), 검색/명령팔레트, **Test/Prod 글로벌 토글**, 알림, 언어·테마 토글.
- 메인 캔버스: Scene 단위 작업 중심 2~3분할.
- 상태/프로그레스 바: 하단, 자동화/렌더 진행률.

사이드바 계층 예시
```
NK_Studio
├ Dashboard (Scene 허브)
├ Scenes & Pipelines
├ Media Lab (Image/Video/Audio)
├ Voice & Subtitles
├ Results Queue (파이프라인 하위 개념)
└ Publish (강조도 낮춤)
```

## 화면별 러프 와이어프레임

### 1) Dashboard (Scene 허브)
- 상단 카드: "새 Scene 파이프라인 시작"(Scene 자동 실행·개별 재시도), "Test Mode로 일부 Scene만"(Scene 선택 힌트), "실패 Scene만 다시 만들기"(원인→재시도→직접 교체 흐름 강조).
- 중앙: **파이프라인 카드** = 이름, 진행률, 모드(Test/Prod), 실패 Scene 여부(배지)만 노출. Scene 수치 상세는 카드 클릭 후로 이동.
- 우측: **AI 작업 로그**(원인/결과/자동·수동 여부 표기) + 단계 큐(현재 실행 Scene 강조) + 크레딧/리소스 사용량(씬당 예상 소모 포함).

```
┌──────── Dashboard ────────┐
│ [새 프로젝트][템플릿]    [최근 이어하기]
│───────────────────────────│
│ 진행 중 프로젝트 카드 2~3열 그리드                │
│───────────────────────────│
│ 우측 패널: 자동화 이벤트 / 단계 상태 / 사용량        │
└───────────────────────────┘
```

### 2) Scenes & Pipelines
- 좌: Scene 리스트(순서/잠금), 상태 배지(대본/TTS/이미지 완료, 실패, 수동 첨부).
- 중: Scene 상세(스크립트, 프롬프트, TTS 상태, 실패 사유).
- 우: **재생성/재시도/직접 교체** 액션 + 중립 포맷(Vertical 9:16 ≤60s / Square 1:1 / Horizontal 16:9). 플랫폼 명칭은 배포 단계에서만.

### 3) Media Lab
- 탭: Image / Video / Audio.
- Image: 프롬프트 + 스타일 슬라이더 + 시드, 결과 갤러리(모자이크), 선택 시 우측 메타/리롤.
- Video: 텍스트→비디오, 참고 이미지/비디오 업로드, 길이/비율 선택, 썸네일 미리보기.
- Audio: TTS/더빙, 목소리 선택, 감정/말속도, 스크립트 라인별 미리듣기.

### 4) Timeline · Edit (간소화)
- Scene 단위 미리보기 + 최소 컷/트림/자막 오버레이.
- Test Mode: 저해상·단축 길이만.

```
┌ Scene 리스트 ┬────── Scene 상세 ──────┬ 액션/상태 ┐
│ 상태 배지    │ 미리보기/스크립트/이미지 │ 재생성/재시도 │
└─────────────┴─────────────────────────┴───────────┘
```

### 5) Voice & Subtitles
- 좌: 자동 전사 결과(타임코드), 라인별 수정/잠금.
- 우: 선택된 라인 프리뷰 + 음성 선택 + 피치/속도/감정.
- 하단: 자막 스타일 프리셋(폰트, 배경, 애니메이션) 실시간 반영.

### 6) Results Queue & Publish
- 테이블: Scene 단계별 상태(대본/TTS/이미지/렌더), 상태(대기/실행/완료/오류), ETA, 크레딧 예상. **현재 실행 Scene 하이라이트**.
- 우측: 포맷 프리셋(Vertical/Square/Horizontal). 플랫폼 명칭은 배포 단계에서만 노출.
- 완료 후: 다운로드, 실패 Scene만 재시도/교체, 리렌더.

### 8) Assets Library
- 그리드/리스트 토글, 필터(타입/날짜/프로젝트), 태그, 라이선스/출처 뱃지.
- 배치 작업: 삭제/이동/라벨/워터마크 제거(허용 범위 표시).

### 9) Settings
- 워크스페이스/팀, 결제·크레딧, 모델 선택(클라우드/로컬), 저장소/백업, 단축키 매핑.

## 반응형 가이드
- ≥1440: 3컬럼 가능(좌 패널 + 메인 + 우 패널).
- 1200~1024: 우측 속성 패널을 드로어로 전환.
- ≤768: 사이드바 아이콘화, 타임라인 단순화(클립 카드 리스트) + 필수 컨트롤만 떠있는 플로팅 바.

## 브랜드/시각 요소
- 버튼: 프라이머리(#FF7A00), 세컨더리(다크 바탕 + 틸 텍스트), 섀도우 y=6 blur=14.
- 아이콘: 라운드 코너, 2px 스트로크, 흰색/틸/오렌지 제한.
- 그래픽: 배경에 대각선 라인/노이즈 패턴, 카드 상단에 얇은 컬러 바(섹션 구분).

## 초기 온보딩 흐름
1) 프로젝트 생성 모달: 목적/플랫폼/길이/톤 선택 → 템플릿 추천.
2) 리서치 → 대본 → 미디어 생성 → 타임라인 → 더빙/자막 → 렌더 → 배포 순서로 상단 프로그레스 스텝.
3) 각 스텝에 "AI 제안" 버튼과 "수동 편집" 토글 병행.
