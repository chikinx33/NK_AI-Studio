# NK_Studio 서비스 지침서 (사용자 관점)

## 1. 제품 정체성과 목적

- **최종 정체성**: NK AI Studio는 단순한 생성툴이 아니라 `Creator Operating System`을 지향한다.
- **현재 목표**: 1인 크리에이터가 `콘텐츠 제작 -> 브랜드 운영 -> 채널 배포 -> 반응 분석 -> 전략 개선` 흐름을 하나의 플랫폼에서 운영할 수 있게 만든다.
- **지향점**: 협업 중심 그룹웨어가 아니라, 개인 제작자의 생산성 극대화, 브랜드 문맥 유지, AI 결과의 투명한 제어를 우선한다.

## 2. 주요 사용자

- 영상 아이디어를 자주 테스트하는 1인 크리에이터, 인플루언서, 강사
- 짧은 포맷 반복 제작이 많은 쇼츠/릴스 제작자
- 시나리오, 이미지, 음성, 편집을 자동화하고 싶지만 결과를 세밀히 조정하고 싶은 사용자
- 여러 프로젝트/IP를 동시에 운영하며 브랜드 문맥을 유지한 채 SNS와 배포까지 연결하고 싶은 사용자

## 3. 핵심 가치

- **Project 중심 운영**: 모든 제작, 운영, 배포, 분석은 Project 문맥 안에서 움직인다.
- **Scene 단위 자동화**: 대본, 이미지, TTS, 편집 규칙을 각각 재시도하거나 교체할 수 있다.
- **Brand 운영 연결**: Creative 결과물을 Brand Studio로 바로 이어서 SNS 콘텐츠와 배포로 확장한다.
- **AI 작업 로그**: 수정, 재시도, 실패 사유를 남겨 신뢰와 비용을 관리한다.
- **사용자 편의성 우선**: 구조가 복잡해져도 사용자는 단순하고 자연스러운 흐름으로 느껴야 한다.

## 4. 시스템 레이어

- **Project Core**: 프로젝트 정보, 브랜드 문맥, 채널, 대표 자산
- **Creative Studio**: 영상, 이미지, 음원, 문서 제작
- **Brand Studio**: SNS 콘텐츠 생성, 캡션, 해시태그, 업로드, 예약 게시
- **Knowledge Hub**: 캐릭터, 세계관, 브랜드 규칙, 참조 콘텐츠
- **Brand Intelligence**: 채널 반응 분석, 콘텐츠 성과 분석, 전략 추천

## 5. 사용 범위

- **Creative 범위**: 시나리오 작성 -> 이미지/음성 생성 -> 자동 컷/자막/전환 -> 테스트/파이널 렌더
- **Brand V1 범위**: SNS 콘텐츠 생성, 캡션 생성, 해시태그 생성, 채널 연결, 업로드, 예약 게시
- **비포함(초기 1.0)**: 팀 협업, 담당자 지정, 고급 캠페인 운영, 전략 자동 추천의 완전 자동화

## 6. 기본 플로우

1. Project 선택 또는 생성
2. Creative Studio에서 콘텐츠 제작
3. 결과물을 Content Library에 저장
4. Brand Studio에서 SNS/마케팅용 콘텐츠로 변형
5. 채널 선택 후 업로드 또는 예약 게시
6. 반응 데이터 축적
7. Brand Intelligence에서 분석 및 향후 전략 반영

## 7. 제어 지점

- **씬 단위**: 재생성, 재시도, 직접 교체, 실패 원인 확인
- **편집 규칙**: 컷 분할 기준, 자막 위치, 컷 길이 보정, 전환 효과 재적용
- **브랜드 문맥**: Project별 브랜드 요약, 핵심 메시지, 금지 표현, 참조 자산 유지
- **채널 운영**: 콘텐츠별 채널 선택, 캡션/해시태그 조정, 예약 게시

## 8. 비용·자원 관리

- 크레딧/스토리지 표시
- Test Mode로 비용 최소화
- 실패 씬만 재생성하여 비용 집중
- Brand 운영 단계에서도 게시 실패/재시도를 분리 관리

## 9. 품질·신뢰 장치

- AI 작업 로그
- 실패 씬만 재생성
- 프로젝트별 브랜드 지식 저장
- 규칙 기반 편집과 운영

## 10. 사용성 원칙

1. 사용자는 현재 어떤 Project 안에 있는지 항상 즉시 이해할 수 있어야 한다.
2. 자주 쓰는 액션은 먼저, 고급 기능은 뒤에 배치한다.
3. Creative 결과물을 Brand 운영으로 넘기는 과정은 짧고 자연스러워야 한다.
4. 시스템이 복잡해져도 사용자는 한 개의 연속된 흐름으로 느껴야 한다.

## 11. 온보딩 가이드

1. Project 생성
2. Creative Studio 또는 Brand Studio 중 원하는 시작점 선택
3. Creative 결과물은 Content Library에 저장
4. Brand Studio에서 콘텐츠 변형 후 채널 선택
5. 업로드 또는 예약 게시

## 12. 확장 로드맵

- V1: Brand Operations
- V1.5: Knowledge-driven content
- V2: Brand Intelligence
- V3: Creator OS

---

**한 줄 정의**

NK_Studio는 제작부터 브랜드 운영, 배포, 분석까지를 Project 문맥 안에서 연결하는 Creator Operating System을 1인 크리에이터에게 제공한다.
