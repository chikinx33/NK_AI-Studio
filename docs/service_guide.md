# NK_Studio 서비스 지침서 (사용자 관점)

## 1. 제품 정체성과 목적
- **목표**: 1인 크리에이터가 “아이디어 → Scene 단위 데이터 → AI 자동화 → 영상 완성”을 빠르게 반복할 수 있는 **자동화 파이프라인 엔진**을 제공한다.
- **지향점**: 협업/프로젝트 관리 도구가 아닌, **개인 제작자의 생산성 극대화**와 **AI 결과의 투명한 제어**.

## 2. 주요 사용자
- 영상 아이디어를 자주 테스트하는 1인 크리에이터, 인플루언서, 강사.
- 짧은 포맷(30s~60s) 반복 제작이 많은 쇼츠/릴스 제작자.
- 시나리오·이미지·음성·컷 편집을 한 번에 자동화하고 싶지만, 결과를 세밀히 조정할 수 있어야 하는 사용자.

## 3. 핵심 가치
- **Scene 단위 자동화**: 대본/이미지/TTS/편집 규칙을 각각 재시도·교체 가능.
- **Test / Production 이원화**: 저비용 테스트 후 선택 씬만 최종 렌더.
- **AI 작업 로그**: 스크립트 수정, 프롬프트 보정, TTS 재시도 사유를 기록하여 신뢰/비용 관리.
- **규칙 기반 편집**: “편집 규칙 재적용” 중심 UX로 손편집 없이도 일관성 유지.

## 4. 사용 범위
- **포맷**: Vertical 9:16(≤60s), Square 1:1, Horizontal 16:9.
- **제작 범위**: 시나리오 작성 → 이미지/음성 생성 → 자동 컷·자막·전환 → 저해상 테스트/파이널 렌더.
- **비포함(초기 1.0)**: 팀 협업, 담당자 지정, 플랫폼별(YouTube/TikTok) 프리셋 강조, 복잡한 타임라인 편집.

## 5. 기본 플로우
1. **시나리오 작성 (GPT API)**  
   - 주제, 영상 목적(대·소분류 토글), 시청 타겟, 영상 길이(15s~2h), 톤/스타일, 추가 항목을 입력.  
   - 필수 조건 미충족 시 알림으로 안내.
2. **Scene 생성**  
   - 5개 씬 카드가 생성되고, 각 씬별 재생성/수정/삭제 가능.  
   - 구분선으로 씬 간 상태를 시각적으로 분리.
3. **Test Mode 실행**  
   - 일부 씬만 저해상·저비용으로 확인. 실패 씬만 재시도 가능.
4. **규칙 재적용 / 교체**  
   - TTS 재생성, 컷 길이 재보정, 자막/전환 규칙 재적용 중 선택.
5. **Production 렌더 & 배포 준비**  
   - 최종 컨펌된 씬이 “씬 파이프라인”으로 이동해 파이널 렌더 및 배포 단계로 이어짐.

## 6. 제어 지점
- **씬 단위**: 재생성/재시도, 직접 교체, 실패 원인 로그 확인.
- **편집 규칙**: 컷 분할 기준, 자막 생성/위치, 컷 길이 보정, 전환 효과를 한 번에 재적용.
- **모드 전환**: Test/Prod를 상단 토글로 항상 노출, 비용 인지 명확화.

## 7. 비용·자원 관리 (초안)
- 크레딧/스토리지 표시: 사용률%와 대략적 소모 힌트(예: Scene당 0.3 크레딧).  
- Test Mode: 저해상·짧은 길이로 비용 최소화, 선택 씬만 생성.

## 8. 품질·신뢰 장치
- AI 작업 로그: 스크립트 버전 변경, 프롬프트 보정, TTS 재시도 및 실패 사유를 기록·표시.
- 실패 씬만 재생성: 비용과 시간을 집중 투자.
- 편집 규칙 중심 UI: 수동 편집 대신 규칙 재적용을 권장.

## 9. 온보딩 가이드 (사용자)
1) 좌측 사이드바에서 **시나리오(GPT)** 진입.  
2) “개요”에서 필드 입력 → **시나리오 생성**.  
3) 우측 “씬 생성”에서 생성된 5개 씬을 확인, 필요한 씬만 재생성/수정/삭제.  
4) **최종 컨펌 → 씬 파이프라인** 버튼으로 파이프라인에 전달.  
5) 대시보드에서 Test/Prod 상태 및 실패 씬 여부 확인 후 렌더.

## 10. 확장 로드맵 (제안)
- 실제 OpenAI API 연동 및 비용 추적.
- Scene 상세 화면: 대본/이미지 프롬프트/TTS 상태/재시도/직접 첨부 UI.
- 규칙 프리셋 저장·재사용, 사용자 정의 컷/자막 규칙 템플릿.

---

**한 줄 정의**  
NK_Studio는 “AI가 한 일을 숨기지 않고, 사람이 다시 잡을 수 있게 만든 Scene 기반 영상 자동화 파이프라인”을 1인 크리에이터에게 제공한다.
