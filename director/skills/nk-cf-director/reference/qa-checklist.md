# 검수 체크리스트

생성 결과를 사용자에게 보여 주기 전에 반드시 수행한다. 기계 검수(스크립트)와 눈 검수(프레임 확대)를 둘 다 한다.

## 1. 기계 검수: `scripts/qa_video.py`

```bash
python3 scripts/qa_video.py VIDEO.mp4 --out qa_out --cuts "0,1.5,2.3,3.0,4.2" [--whisper] [--frames "2.4,5.1"]
```

출력(`qa_out/`):
- `report.json`
  - 길이·해상도·fps·코덱
  - 실제 장면 전환 시각(`sceneCuts`)과 콘티 컷 시각의 차이(`cutAlignment`)
  - 오디오 음악 의심 구간(`audio.musicSuspect`, 초당 지속 배음선 개수 `audio.perSecond[].lines`)
  - 대사 전사(Whisper, 선택)
  - 디코딩 오류 여부
- `spectrogram.png`: 수평 배음선이 이어지면 음악이다.
- `frames/`: 각 컷 중앙과 `--frames`로 지정한 시각의 프레임(원본 해상도). 확대 검수에 쓴다.

필요 패키지: `ffmpeg`, `numpy`, `scipy`. Whisper는 `faster-whisper`가 있을 때만 동작한다.

## 2. 판정 항목

| # | 항목 | 확인 방법 | 불합격 예 |
|---|---|---|---|
| 1 | 피드백 해결 | 이전 버전 같은 컷과 나란히 비교 | 지적 사항이 "일부 남음" |
| 2 | 컷 구성 | `sceneCuts` vs 콘티 | 컷 누락, 예정에 없던 컷 추가, 0.7초 이상 어긋남은 메모 |
| 3 | 연속 무브 | 해당 구간에 컷 전환 0, 프레임 육안 확인 | 디졸브·이중 노출·배경이 겹쳐 바뀜 |
| 4 | 음악 | `audio.musicSuspect` + 스펙트로그램 + 청취 | 지속 배음·화음(약 −50~−65dBFS도 불합격) |
| 5 | 대사 | 전사 결과 | 지시와 다른 대사(예: "어이쿠" 대신 "오잇"은 메모) |
| 6 | 손 | 프레임 확대 | 손가락 수 이상, 성별에 안 맞는 손, 소품 비율 |
| 7 | 얼굴·화장 | 눈 주변 확대 | 무화장 설정인데 아이라인 |
| 8 | 글자·소품 | 확대 | 명함·UI 문구 오탈자, 마스코트 소품 글자 누락 |
| 9 | 연속성 | 컷 순서대로 넘기기 | 소품 사라짐, 의상 변화, 차선 침범, 동선 반대 |
| 10 | 스타일 | 기준 컷과 비교 | 실사 질감 혼입, 지정 금지 요소(예: 기와지붕) 등장 |
| 11 | 프로젝트 고정 규칙 | 메모리의 규칙 목록 | 예: 인물이 울타리 밖, 마스코트 표정 어두움 |

## 3. 보고 형식

```
드래프트 1 검수 (20.04초, 854×480, 24fps)
통과: C01~C06 구성, C05 랙포커스, C08 명함 문구 정확 …
메모: C09 시작 0.7초 늦음(편집으로 조정 가능)
불합격: 약 9초부터 음악성 지속음, 16초 이후 화음 → 완성본에도 그대로 이어지므로 편집에서 9초 이후 생성 오디오 미사용 권장
다음 선택지: ① 이대로 1080p 완성(오디오는 편집 처리) ② 프롬프트 보강 후 드래프트 재생성(약 $2.7)
```

- 합격과 불합격을 타임코드와 함께 쓴다. 불확실하면 확대 프레임을 함께 보여 준다.
- "정상"은 확대 확인을 마친 항목에만 쓴다.
- 결함을 숨기지 않는다. 사용자가 먼저 발견하면 신뢰를 잃는다.

## 4. 스크립트 판정 기준의 근거 (2026-10-13 실측 보정)

대부금융협회 운동장 1080p 5편(사람이 검수한 기록이 있는 영상)으로 맞췄다.
- 효과음·대사만 있는 영상: 지속 배음선이 매초 0줄이었다.
- 음악이 섞인 구간: 매초 2~12줄이었다.
- 기준은 "평균 1줄 이상이 2초 이상 지속"이다. 에너지 비율 기준은 큰 효과음에 묻혀 놓쳤기 때문에 쓰지 않는다.
- 낮은 레벨(−50~−65dBFS)의 음악도 잡는다. 그래도 최종 판정은 스펙트로그램과 청취로 확인한다.
