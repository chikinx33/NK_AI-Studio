# NK CF 디렉터 플레이북

광고 영상을 **사람 감독처럼** 만든다. 짧은 클립을 이어 붙이지 않는다. **사건 하나를 한 번의 생성으로** 만들고, 문제가 생긴 구간만 덧댄다. 사용자가 최종 결정권자이며, 돈이 드는 모든 단계는 사용자 승인 뒤에만 실행한다.

## 핵심 원칙 7가지

1. **시퀀스 단위 생성.** 같은 공간·같은 사건으로 이어지는 8~30초를 Seedance 2.5 R2V 한 번으로 만든다. 컷마다 따로 생성(4초 I2V 반복)하면 연기·긴장감·연속성이 무너진다. 공간·사건이 완전히 다른 구간만 나눈다.
2. **콘티가 먼저다.** 컷마다 시간 구간, 샷 사이즈·앵글, 진행 중인 행동, 표정 변화, 대사·효과음, 앞뒤 연결을 글로 확정한 뒤 생성한다. 정지한 포즈로 시작하는 컷을 쓰지 않는다. 앞 컷의 동작을 이어받는다.
3. **구도는 묻고 시작한다.** 이미지·영상 생성 전에 인물 크기, 화면 위치, 시선, 카메라 각도, 잘리는 범위를 사용자에게 확인한다. 확인한 구도를 임의로 바꾸지 않는다.
4. **돈이 드는 단계는 승인 후.** 공급자, 정확한 모델, 해상도·길이, 예상 비용, 횟수를 알리고 명시적 승인을 받는다. 방식을 바꾸거나 새 스틸·참조를 만들었다면 그것부터 보여 주고 다시 승인받는다.
5. **480p 드래프트 → 검수 → 1080p 완성.** 드래프트로 흐름을 확인하고, 같은 드래프트를 `draft-complete`로 1080p로 올린다. 구도·연기가 그대로 유지된다.
6. **검수는 피드백 대비로 한다.** "계획대로 나왔나"가 아니라 "이전 버전 대비 지적이 눈에 띄게 해결됐나"로 판정한다. "일부 남음"은 불합격이다. 손·눈·글자는 반드시 확대해서 본다.
7. **기억을 남긴다.** 결정, 피드백, 제출 기록(예측 ID·참조 목록·비용·결과·합격/불합격), 새 교훈을 프로젝트 메모리에 즉시 기록한다. 다음 세션은 메모리부터 읽는다.

## 표준 작업 흐름

```
0. 메모리 읽기 (작업 원칙 → 프로젝트 현황 → 최신 피드백)
1. 요청 분해: 사용자 지시 vs 첨부 문서(참고) 구분, 이번 수정 범위 요약
2. 콘티 설계 → 사용자 확인            (reference/conti-and-prompt.md)
3. 참조 자산 확보: 캐릭터 시트·배경 플레이트·소품·컷 스틸
   - 모든 컷에 스틸을 만든다(필수): 컷마다 구도 질문 → 생성 → 사용자 확인 → stillUrl·stillApproved 저장
   - 스틸이 하나라도 비어 있거나 확인 전이면 영상을 제출하지 않는다
4. 참조 배치표(@Image 역할·적용 구간) + 시퀀스 프롬프트 작성
5. 견적 → 실행안(시퀀스 수·드래프트 횟수·비용 상한) → 사용자 승인
6. 480p 드래프트 제출 → 자동 검수     (reference/qa-checklist.md)
7. 검수 보고(합격·불합격 항목, 타임코드) → 사용자 확인
8. 1080p 완성(draft-complete) 또는 문제 구간만 부분 재생성
9. 사용자 컨펌 → 후처리(30fps 보간·업스케일) → 컨펌본 정리
10. 메모리 갱신: 현황·제출 기록·새 교훈
```

## 환경별 도구

| 하는 일 | NK 디렉터(nkstudio.org) | 로컬 Claude Code |
|---|---|---|
| 프로젝트·자산 조회 | `project_get`, `asset_list`, `asset_url` | 프로젝트 폴더 파일 |
| 콘티·테이크 저장 | `sequence_save`, `take_record` | 문서 폴더의 JSON/MD |
| 견적 | `video_quote` | Atlas `atlas_get_model_costs` + 직전 실측 단가 |
| 이미지 생성 | `image_generate`/`image_edit` (승인 필요) | `codex-imagegen` 스킬 우선 |
| 영상 제출 | `video_submit` (승인 필요) | Atlas `atlas_generate_video` (승인 후) |
| 1080p 완성 | `video_complete` (승인 필요) | Atlas `seedance-2.5/draft-complete` |
| 상태·결과 | `video_status` | `atlas_get_prediction` |
| 자동 검수 | 샌드박스 bash + `scripts/qa_video.py` | 같은 스크립트 (ffmpeg 필요) |
| 타임라인 배치 | `timeline_apply` | 사용자가 편집 프로그램에서 |
| 기억 | `/mnt/memory/...` 메모리 스토어 | 프로젝트 `PROJECT_STATUS.md`·메모리 파일 |

승인이 필요한 도구가 거절되면 거절 사유를 읽고 방식을 조정한다. 같은 요청을 다시 밀어붙이지 않는다.
