# 모션 키트 글꼴

모두 상업적으로 쓸 수 있고, 영상에 출처를 적을 필요가 없는 글꼴이다(2026-10-21 엔케 기준: 출처 표기 필요·비상업용 금지).
렌더는 인터넷을 막고 하므로 파일을 여기에 둔다. `lib/fonts.css`의 이름으로 쓴다.

| 이름(font-family) | 느낌 | 라이선스 | 출처 |
|---|---|---|---|
| Pretendard (굵기 45~920) | 요즘 가장 많이 쓰는 깔끔한 고딕, 정보·수치 | SIL OFL 1.1 (OFL-pretendard.txt) | npm pretendard 1.3.9 |
| SUIT (굵기 100~900) | 단정하고 또렷한 고딕 | SIL OFL 1.1 (OFL-suit.txt) | github sun-typeface/SUIT |
| NK Sans = Noto Sans KR (100~900) | 표준 고딕 | SIL OFL 1.1 | Windows 글꼴 폴더 |
| NK Serif = Noto Serif KR (200~900) | 묵직한 명조, 격식·역사 | SIL OFL 1.1 | 시즌1 키트 |
| Nanum Gothic ExtraBold | 두꺼운 고딕 | SIL OFL 1.1 | Windows 글꼴 폴더 |
| Black Han Sans (검은고딕) | 아주 굵은 제목, 강렬 | SIL OFL 1.1 (OFL-blackhansans.txt) | github google/fonts |
| Do Hyeon (도현) | 굵고 단단한 제목 | SIL OFL 1.1 (OFL-dohyeon.txt) | github google/fonts |
| Jua (주아) | 둥글고 귀여운 제목 | SIL OFL 1.1 (OFL-Jua.txt) | 시즌1 키트 |
| Dongle (동글, 700) | 동글동글 귀여움 | SIL OFL 1.1 (OFL-dongle.txt) | github google/fonts |
| Gowun Dodum (고운돋움) | 부드러운 고딕, 따뜻함 | SIL OFL 1.1 (OFL-gowundodum.txt) | github google/fonts |
| Gowun Batang (고운바탕 400·700) | 부드러운 명조, 문학·감성 | SIL OFL 1.1 (OFL-gowunbatang.txt) | github google/fonts |
| Nalgae (학교안심 날개) | 부드러운 손글씨풍 | 학교안심 글꼴, 상업용 무료 | 시즌1 키트 |
| Gaegu (개구, 700) | 장난스러운 손글씨 | SIL OFL 1.1 (OFL-gaegu.txt) | github google/fonts |
| Nanum Pen Script (나눔손글씨 펜) | 펜 손글씨 | SIL OFL 1.1 (OFL-nanumpenscript.txt) | github google/fonts |
| Hi Melody (하이멜로디) | 귀여운 손글씨 | SIL OFL 1.1 (OFL-himelody.txt) | github google/fonts |
| KOTRA Hope (KOTRA 희망체) | 손글씨 | KOTRA 희망체, 상업용 무료 | 사이트 사용 중 |

OFL 은 글꼴 파일을 다른 곳에 나눌 때 라이선스 문서를 함께 두라는 조건만 있고, 글꼴로 만든 영상·그림에는 출처를 적을 필요가 없다.
