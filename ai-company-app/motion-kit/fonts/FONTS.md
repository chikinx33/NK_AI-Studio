# 모션 키트 글꼴

모두 상업용 무료 글꼴이다. 렌더는 인터넷을 막고 하므로 파일을 여기에 둔다. `lib/fonts.css`의 이름으로 쓴다.

| 이름(font-family) | 파일 | 느낌 | 라이선스 |
|---|---|---|---|
| NK Sans | NotoSansKR-VF.ttf (굵기 100~900) | 깔끔한 고딕, 정보·수치 | SIL OFL 1.1 (Google Noto) |
| NK Serif | NotoSerifKR-VF.ttf (굵기 200~900) | 묵직한 명조, 판타지·격식 (엘리더스 시즌1) | SIL OFL 1.1 (Google Noto) |
| Nanum Gothic ExtraBold | NanumGothicExtraBold.ttf | 두꺼운 고딕 제목 | SIL OFL 1.1 (네이버 나눔) |
| Jua | Jua-Regular.ttf | 둥글고 귀여운 제목 (퍼즐나이트 시즌1) | SIL OFL 1.1 (OFL-Jua.txt) |
| Nalgae | Hakgyoansim_NalgaeR.ttf | 부드러운 손글씨풍 (네코반 시즌1) | 학교안심 글꼴, 상업용 무료 |
| KOTRA Hope | KOTRAHOPE.woff2 | 손글씨 | KOTRA 희망체, 상업용 무료 (사이트에서도 사용 중) |

원본 출처: 시즌1 키트 `F:\NKW\App\Game-Management\promo\_motion\fonts`, Windows 글꼴 폴더(Noto Sans KR·나눔고딕), `prototype/fonts/KOTRAHOPE.woff2`.
