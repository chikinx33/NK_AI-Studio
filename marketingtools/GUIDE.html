🤝이 프로젝트 작동 원리 — 당신과 AI의 역할 분담

핵심 메시지: AI는 "글 쓰고 그림 그리는 작업자". 당신은 "정보를 주고 결정을 내리는 감독자". 작업 90%는 AI가 합니다.
✋
당신 (Human)
정보 제공 · 결정 · 외부 가입
  • 본인 브랜드 정보 메모해서 주기 (한 번만)
  • 외부 사이트 가입 및 API 키 발급 (Google AI Studio, Buffer)
  • 레퍼런스 이미지 모으기 (Pinterest 등)
  • 결제 카드 등록
  • 결과물 보고 피드백 ("이건 좋아 / 저건 별로야")
  • 방향 결정 ("이번 주는 OO 주제로 가자")
🤖
Claude Code (AI)
실행 · 작성 · 생성
  • 폴더/파일 생성 모두 자동
  • context/ MD 3종 작성 (당신이 준 정보 기반)
  • templates/ MD 4종 작성 (디자인 규칙)
  • CLAUDE.md SOP 자동 생성
  • 에이전트 4종 자동 생성 + 라우팅 룰
  • 카드뉴스/썸네일/PPT/뉴스레터 모두 자동 제작
  • 검수 + Buffer 예약 포스팅까지
💡 영상의 핵심 통찰
"실행보다 사전 준비(컨텍스트)에 95%의 시간을 투자하라."
→ 당신이 정보를 잘 정리해서 주면, 그 뒤는 AI가 알아서 합니다. 이 가이드는 그 "95%"를 효율적으로 채우는 방법입니다.

✋ STEP B API 키 2개 발급 (외부 사이트)

B 사람이 직접 가서 발급해야 하는 키 2개
이 단계는 AI가 대신 해줄 수 없어요. 외부 사이트에 가입하고 키를 받아 와야 합니다. 약 15분 소요.
🍌
Nano Banana (Gemini)
이미지 생성용 — 필수
  1. aistudio.google.com 접속
  2. Google 계정 로그인
  3. 왼쪽 메뉴 → Get API Key
  4. "API 키 만들기" → 이름 입력 → 발급
  5. 키를 안전한 곳에 복사
  6. 결제 계정 연결 (Google Cloud Console)
⚠️ 결제 필수
무료 등급은 품질 제한 있음. 카드뉴스 5장 ≈ 약 250원. 한도 설정 권장.
📲
Buffer
SNS 자동 포스팅용 — 선택
  1. buffer.com 가입 (무료 OK)
  2. SNS 채널 연동 (인스타/링크드인 등)
  3. developers.buffer.com 접속
  4. Access the Beta → Generate Key
  5. 이름 입력 → API 키 발급
  6. 키를 즉시 복사 (다시 못 볼 수도)
💡 Phase 8에서 사용
콘텐츠 자동 배포 단계에서 필요. 일단 만들기만 하고 나중에 써도 됨.
🔒 보안 5계명 (필독)
1) GitHub에 절대 올리지 마세요  ·  2) 메시지/이메일로 공유 금지  ·  3) 스크린샷/영상 녹화 시 가리기  ·  4) 노출 시 즉시 폐기 후 재발급  ·  5) 사용 한도 설정 (예상치 못한 과금 방지)

🤖 STEP E MCP 설치 — Nano Banana 연결

E 이미지 생성을 위한 외부 도구 연결

📋 복붙용 프롬프트
프로젝트 루트에 .env 파일과 .env.example을 만들어줘. 다음 변수 포함: GEMINI_API_KEY= BUFFER_API_KEY= .gitignore에 .env 추가해줘.

🔑 3) API 키 입력 (당신이 직접)

✋ 사람이 해야 함

🤖 STEP F 에이전트 4종 자동 생성

F "리서치→콘텐츠→디자인→검수" 파이프라인 구축
마지막 셋업 단계. 4개 에이전트를 한 번에 만들고, CLAUDE.md에 라우팅 룰까지 자동 추가합니다.
📋 복붙용 프롬프트
클로드 코드의 공식 가이드라인에 따라 서브에이전트 4개를 만들어줘. 리서치 → 콘텐츠 → 디자인 → 검수 4단계 파이프라인으로 구성하고 .claude/agents/ 폴더에 다음 파일을 생성해줘: - research-agent.md (리서치, model: sonnet) - content-agent.md (카피 작성, model: sonnet) - design-agent.md (이미지/PPT 생성, model: sonnet) - review-agent.md (브랜드 톤 검수, model: sonnet) 각 에이전트는 context/의 brand-guideline.md, business-context.md, design-style-guide.md를 참조하도록 설정하고 templates/의 해당 템플릿도 참조하도록 해줘. 마지막으로 CLAUDE.md에 에이전트 라우팅 규칙도 추가해줘.

🎯 STEP G 본 게임 — 첫 콘텐츠 만들기 ⭐

G 한 줄 명령으로 마케팅 자료 4종 자동 생성
셋업이 끝나면 이제 정말 한 줄 명령으로 모든 마케팅 자료가 만들어집니다. 이게 이 프로젝트의 핵심 약속!

🧪 먼저 가볍게 — 카드뉴스 1세트 테스트

📋 가벼운 시작 — 카드뉴스 5장만
[다루고 싶은 주제]에 대한 카드뉴스 5장 만들어줘. templates/card-news-template.md와 context/의 모든 파일을 참조하고 Nano Banana MCP로 이미지 생성, output/card-news/에 저장해줘.

🚀 메인 시나리오 — 전체 캠페인 자동 생성

📋 모든 자료 한 번에 (영상의 메인 시연)
[이번 주 캠페인 주제] 마케팅 캠페인을 만들어줘. 모든 자료(카드뉴스, 썸네일, PPT, 뉴스레터)를 만들어줘. 모든 에이전트 팀(research → content → design → review)을 가동해서 진행하고 결과물은 output 폴더에 종류별로 저장해줘. 작업 순서: 1. research-agent로 주제 리서치 (output/research/) 2. content-agent로 카피 작성 3. design-agent로 이미지/PPT 생성 4. review-agent로 검수 마지막에 모든 산출물 파일 경로 + 검수 보고서 요약 보여줘.
⏱️ 예상 실행 시간
약 10~15분 — 그동안 사용자는 다른 일 하세요. 완료되면 output/ 폴더에 4종 산출물이 다 들어있습니다.
🎬 영상 시연 포인트
"한 줄 명령으로 카드뉴스/썸네일/PPT/뉴스레터가 다 나옵니다" — 이게 영상의 클라이맥스. 이 단계를 시청자에게 보여줄 때 가장 임팩트 있어요.

✋ STEP H 피드백 루프 — 결과물 마음에 안 들 때 ⭐

H "결과물을 고치지 말고, 컨텍스트를 고쳐라"
가장 중요한 슬라이드. 첫 결과물이 마음에 안 들 때, 어떻게 개선하느냐가 이 시스템의 성패를 가릅니다.

❌ 잘못된 접근 (대부분이 하는 실수)

매번 결과물만 수정
"이 카드뉴스 톤이 별로야, 다시 만들어줘"
→ AI가 다시 만들지만 다음에도 같은 실수 반복.
매번 같은 피드백을 줘야 합니다. 비효율의 끝.

✅ 올바른 접근 (영상의 핵심 철학)

컨텍스트(context/, templates/)를 수정
"이 부분이 별로야"라고 느낀 점을 context 파일에 영구히 기록합니다. 다음부터는 자동으로 적용됩니다.

🔁 피드백 사이클 (3분 작업)

1
결과물에서 구체적으로 뭐가 별로인지 한 문장으로 적기
2
어떤 컨텍스트 파일에 추가하면 좋을지 판단 (브랜드 톤? 디자인? 비즈니스?)
3
AI에게 명령 (아래 프롬프트 참조)
4
재생성해서 확인 — 좋으면 끝, 안 좋으면 다시
📋 피드백 프롬프트

대부분의 문제는 context 파일이 충분히 구체적이지 않아서 발생합니다. 결과물이 이상하면 항상 context부터 점검하세요.
Q1결과물 톤이 우리 브랜드와 다르게 나옵니다
→ context/brand-guideline.md의 "권장 표현"과 "금지 표현"이 구체적인지 확인. Step H의 피드백 루프 활용.
Q2디자인이 너무 화려하게 나옵니다
→ design-style-guide.md의 "금지 사항" 섹션을 더 강하게. 프롬프트에 minimalist, lots of whitespace 추가.
Q3MCP가 작동하지 않습니다
→ /mcp로 상태 확인 → Claude Code 재시작 → API 키 확인 → 결제 계정 확인 순서.
Q4API 키를 실수로 GitHub에 올렸어요
→ 즉시 발급 사이트에서 키 폐기 → 새 키 발급 → .gitignore에 .env 추가 확인.
Q5한글 폰트가 적용 안 됩니다
→ 시스템에 폰트 설치 필요. Pretendard 추천. macOS: ~/Library/Fonts/에 .otf 복사.

"결과물이 이상하면 → context 점검"
이 한 가지만 기억하면 90%의 문제는 해결됩니다.
