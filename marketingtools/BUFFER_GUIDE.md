# 📤 Buffer API 자동 배포 가이드

> 만들어진 카드뉴스/콘텐츠를 **여러 소셜 미디어에 자동으로 예약 포스팅** 하는 방법.
> 영상의 마지막 단계로, 마케팅 자동화의 화룡점정입니다.
>
> 💡 이 가이드는 `TASK_LIST.md`의 Phase 8 보충 자료입니다.

---

## 🎯 왜 Buffer를 쓰나요?

### 문제 상황
당신이 콘텐츠를 만들었다고 가정해봅시다.
- 인스타그램에 카드뉴스 5장 → 수동 업로드
- 링크드인에 같은 내용 + 텍스트 변형 → 수동 업로드
- X(트위터)에 줄여서 → 수동 업로드
- 쓰레드에 또 → 수동 업로드

**1개 콘텐츠 = 4번 수동 작업**

### Buffer로 해결
한 번 작성 → 여러 플랫폼에 **시간대별 예약 자동 포스팅**

### 본인 브랜드에 왜 적합한가?
- 콘텐츠 본질에 집중할 시간 확보
- 일관된 발행 일정으로 브랜드 신뢰도 상승
- 효과 측정 → 데이터 기반 콘텐츠 전략

---

## 📋 전체 흐름

```
1. Buffer 계정 가입 + SNS 연동
        ↓
2. Buffer Developer API 키 발급
        ↓
3. 프로젝트 .env에 API 키 저장
        ↓
4. Claude Code에 명령: "이 콘텐츠를 [날짜]에 예약 포스팅"
        ↓
5. Buffer 대시보드에서 예약 확인
        ↓
6. 자동 발행 → 성과 측정
```

---

## 🔧 Step 1: Buffer 계정 셋업

### 1-1. 회원가입
🌐 https://buffer.com/

- 무료 플랜: 3개 채널, 월 10개 예약
- 유료 플랜: $5/월부터, 더 많은 채널/예약

### 1-2. 소셜 미디어 연동

대시보드에서 **Connect a channel** 클릭하여 연동:

#### 추천 연동 채널 (브랜드 타겟에 따라 선택)
1. **링크드인** (B2B 타겟에 최적)
2. **쓰레드(Threads)** (긴 텍스트 + 이미지)
3. **X (구 트위터)** (짧은 인사이트)
4. **인스타그램** (카드뉴스 + Reels)
5. **페이스북** (선택)

#### 각 플랫폼별 일반 전략
| 플랫폼 | 콘텐츠 형식 | 발행 빈도 |
|--------|------------|----------|
| 링크드인 | 카드뉴스 + 긴 글 | 주 2~3회 |
| 쓰레드 | 카드뉴스 + 짧은 글 | 주 3~5회 |
| X | 1줄 인사이트 + 영상 링크 | 매일 |
| 인스타그램 | 카드뉴스 + 캡션 | 주 2~3회 |

## 🔑 Step 2: Buffer Developer API 키 발급

### 2-1. Developer 페이지 접속
🌐 https://developers.buffer.com/

> ⚠️ **주의**: 일반 Buffer 페이지가 아니라 **Developer 페이지**입니다.

### 2-2. Personal Access Token 발급

1. 우측 상단 **Access the Beta** 클릭
2. **Generate Key** 버튼 클릭
3. 키 이름 입력 (예: `[본인 프로젝트명]-marketing`)
4. **API 키 생성** 클릭
5. 생성된 키를 **즉시 복사** (다시 볼 수 없을 수도 있음)

### 2-3. Beta 안내
Buffer API는 현재 **베타 단계**입니다:
- 모든 기능이 100% 안정적이지 않을 수 있음
- 소셜 미디어 예약/발행 기본 기능은 검증됨
- 새로운 기능은 점진적으로 추가 중

## 🔐 Step 3: API 키 안전하게 저장

### 3-1. .env 파일 업데이트

프로젝트 루트의 `.env` 파일 열기 (없으면 `.env.example` 복사):

```env
# Google AI Studio (Nano Banana)
GEMINI_API_KEY=기존_키

# Buffer API
BUFFER_API_KEY=발급받은_Buffer_키_여기에
```

### 3-2. 보안 확인
- [ ] `.env` 파일이 `.gitignore`에 포함되어 있는지
- [ ] API 키를 메시지/스크린샷에 노출하지 않았는지
- [ ] 영상 녹화 시 가렸는지

## 🚀 Step 4: Claude Code에서 사용하기

### 명령 패턴 1: 단일 콘텐츠 예약

```
"Buffer API 키를 .env에 저장해놨어.
output/card-news/[YYYY-MM-DD]-[주제]-slide-01.png을
[년도]년 [월]월 [일]일 오후 2시에
링크드인과 쓰레드에 동시 예약 포스팅해줘.

포스팅 본문:
'[브랜드 톤에 맞는 후킹 카피]

[자세히 보기 → 채널 링크]
#[해시태그1] #[해시태그2] #[본인브랜드명]'"
```

### 명령 패턴 2: 카드뉴스 전체 + 본문 자동 생성

```
"output/card-news/[YYYY-MM-DD]-[주제]/ 폴더의
모든 슬라이드를 인스타그램/링크드인에 예약 포스팅해줘.

- 일정: [시작 날짜]부터 매일 오후 2시
- 본문은 templates/card-news-template.md 톤 따라서 작성
- 해시태그: #[해시태그1] #[해시태그2] #[본인 브랜드명]"
```

### 명령 패턴 3: 마케팅 캠페인 전체 일정 배포

```
"output/ 폴더의 이번 주 캠페인 콘텐츠를
다음 일정으로 배포해줘:

월요일 오후 2시: 카드뉴스 (인스타+링크드인)
화요일 오전 10시: 뉴스레터 발송 (이메일은 별도)
수요일 오후 7시: X 짧은 인사이트
목요일 오후 2시: 유튜브 영상 + 썸네일 알림 (모든 채널)
금요일 오후 5시: 한 주 정리 카드뉴스"
```

## 🎨 콘텐츠별 추천 발행 전략

### 📰 카드뉴스 (5~7장)
- **인스타그램**: 5~7장 모두 (한 번에 슬라이드 형식)
- **링크드인**: 5~7장 + 본문 200자
- **쓰레드**: 1~3장 발췌 + 본문 100자
- **X**: 표지 1장 + 영상/풀콘텐츠 링크

### 📧 뉴스레터
- **링크드인**: 핵심 통찰 발췌 + 풀버전 링크
- **이메일**: 메인 채널 (스티비/메일침프 사용)
- **쓰레드**: 시리즈로 분해

### 📊 PPT (사업 소개서)
- **링크드인**: 슬라이드 캡처 5~7장 + 다운로드 링크
- **유튜브**: 영상 컨텐츠로 변환 (선택)

### 🖼️ 썸네일
- 단독 콘텐츠가 아닌 **유튜브 영상 홍보 도구**
- 모든 채널에 영상 알림과 함께 발행

## 🛠 트러블슈팅

### Q1. Buffer API가 응답하지 않아요
- API 키 만료 확인 (Developer 페이지에서 갱신)
- 무료 플랜 발행 한도 초과 (월 10개) 확인
- Buffer 서비스 상태 페이지 확인: https://status.buffer.com/

### Q2. 이미지가 잘려서 올라가요
- 플랫폼별 권장 비율 확인:
  - 인스타그램: 1:1 (1080×1080) 또는 4:5 (1080×1350)
  - 링크드인: 1.91:1 (1200×627)
  - X: 16:9 (1600×900)
- `design-agent`에게 플랫폼별 변형 생성 요청

### Q3. 한글 깨짐 현상
- Buffer 자체는 한글 지원
- 이미지 내 한글이 깨지면 `design-style-guide.md`에서 지정한 폰트가 시스템에 설치됐는지 확인

### Q4. 예약했는데 발행이 안 됐어요
- Buffer 무료 플랜은 **한 채널당 동시 예약 10개 제한**
- 유료 업그레이드 또는 시간 조정

## 🎉 모든 Phase 완료!

이제 본인 브랜드의 마케팅 에이전트 팀이 **100% 자동화** 되었습니다.

### 통합 명령 (모든 시스템 한 번에 가동)

```
"이번 주 [본인 브랜드명] 마케팅 캠페인을 시작해줘.

주제: [이번 주 핵심 주제]

작업 순서:
1. research-agent로 주제 리서치
2. content-agent로 카드뉴스 + 뉴스레터 + 썸네일 카피 작성
3. design-agent로 모든 시각 자료 생성 (Nano Banana + PPTX)
4. review-agent로 검수
5. Buffer API로 다음 주 일정에 예약 포스팅

모든 결과물은 output/에 저장하고,
검수 보고서 + 발행 일정표를 마지막에 보여줘."
```

이 한 줄로 **리서치 → 콘텐츠 → 디자인 → 검수 → 배포**가 모두 자동화됩니다.
