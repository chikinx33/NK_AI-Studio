## 4. 레이아웃 원칙

### 그리드 시스템
- **`[8]`px 베이스 그리드** 사용
- 여백은 `[8]`의 배수
- 카드뉴스: `[1080×1080px]` (인스타) / `[1080×1350px]` (포트레이트)
- 썸네일: `[1280×720px]` (유튜브)

## 5. 카드뉴스 디자인 규칙

### 표지 (1장)
```
┌─────────────────────────┐
│                         │
│  [카테고리 태그]         │
│                         │
│  거대한 헤드라인         │
│  (2~3줄)                 │
│                         │
│  [브랜드명]              │
└─────────────────────────┘
```

### 본문 (2~6장)
- **상단**: 슬라이드 번호 (예: 02 / 07)
- **중앙**: 핵심 메시지 1개 (H2)
- **하단**: 설명/예시 (Body, 2~3문장)
- **모서리**: 작은 로고

### 마지막 장 (CTA)
- "`[CTA 카피 — 예: 다음 영상에서 자세히]`"
- "`[행동 유도 — 예: 구독 + 알림 설정]`"
- 채널 핸들 `[@본인채널]`
