| 항목 | 값 |
|------|-----|

## 3. 표준 구조 (8개 섹션)

### 1) 헤더 (Header)
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[브랜드명] Issue #N
YYYY년 MM월 DD일
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 2) 후킹 타이틀 (Hook Title)
**역할**: 클릭/오픈 유도
- 의문형 또는 도발적 단정
- 12~20자 권장

**예시 (본인 브랜드에 맞게 교체)**:
- "`[의문형 — 예: ~의 진짜 이유]`"
- "`[반전 — 예: ~잘 쓰면 끝이라는 오해]`"
- "`[수치 강조 — 예: ~만 바꿔도 10배]`"

### 3) 인사말 (Greeting, 2~3문장)
```
안녕하세요, [발신자 이름/직함]입니다.

이번 주는 [이번 호 주제]에 대해 이야기해보려 합니다.

여러분도 한 번쯤은 [공감 가는 상황]을 겪어본 적이 있을 텐데요.
```

### 4) 문제 제기 (The Problem, 200~300자)
- 시청자의 페인포인트 구체적 묘사
- 본인 또는 클라이언트 사례로 시작
- "최근 한 분에게 이런 질문을 받았습니다…"

### 5) 본문: 통찰 + 설명 (Main, 800~1200자)
**구조**:
1. **결론 한 줄** (굵게 강조)
2. **왜 그런가** (원리 설명)
3. **비유** (이해를 돕는 메타포)
4. **구체적 예시** (실제 적용 사례)
5. **반례 또는 주의사항**

### 6) 적용법 (How To, 300~500자)
**역할**: 독자가 바로 해볼 수 있는 행동 제시
```
이번 주에 시도해볼 것:

1. [구체적 행동 1]
2. [구체적 행동 2]
3. [구체적 행동 3]
```

### 7) 클로징 (Closing, 2~3문장)
```
이번 호의 핵심은 [한 줄 요약]입니다.

다음 주에는 [다음 호 예고]에 대해 다룹니다.

그럼 좋은 한 주 보내세요.

— [발신자 이름/직함]
```

### 8) CTA & 푸터 (Footer)
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📺 이번 주 추천 영상
[제목] → [URL]

🔗 더 알아보기
- [채널 종류]: [@본인 채널 핸들]
- [유료 상품 1 — 예: 강의 신청]: [링크]
- [유료 상품 2 — 예: 1:1 컨설팅]: [링크]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

이 뉴스레터는 [이메일]에게 발송되었습니다.
[수신 거부] · [친구에게 공유]
```

## 4. 작성 시 체크리스트

### 콘텐츠 관점
- [ ] 결론(통찰) 한 줄을 명확히 정의했나?
- [ ] 비유 1개 이상 포함되어 있나?
- [ ] 적용법 섹션에 구체적 행동 3개 이상 있나?
- [ ] 다음 호 예고가 있나?

### 톤 앤 매너 관점
- [ ] 브랜드 가이드라인의 지양 표현을 쓰지 않았나?
- [ ] 본인 브랜드 톤이 유지되나?
- [ ] 과장된 보장 표현이 없나?

### 기술 관점
- [ ] 모바일 가독성 (한 단락 3문장 이내)
- [ ] 이미지에 alt 텍스트 있나?
- [ ] CTA 링크가 모두 작동하나?
- [ ] 제목이 이메일 미리보기에서 잘리지 않나?

## 7. 제목 작성 가이드 (Subject Line)

### 효과적인 제목 패턴
1. **숫자 + 도발**: "`[예: ~의 95%가 실패하는 이유]`"
2. **반전**: "`[예: ~잘 하면 안 되는 이유]`"
3. **호기심**: "`[예: ~가 숨겨둔 ~의 비밀]`"
4. **개인화**: "`[예: 당신의 ~가 작동하지 않는 진짜 이유]`"

### 피해야 할 패턴
- ❌ "[중요] 꼭 보세요!"
- ❌ "충격!!!"
- ❌ 이모지 남발 (2개 이하 권장)
- ❌ 30자 이상 (모바일에서 잘림)
