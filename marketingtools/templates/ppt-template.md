# PPT 템플릿 (Presentation Template)

> 사업 소개서 / 강의 자료 / 세미나 슬라이드 가이드
> 디자인 원칙은 [[../context/design-style-guide]] 참조
> `[대괄호]` 안의 내용은 본인 브랜드에 맞게 교체하세요

---

## 1. 기본 사양

| 항목 | 값 |
|------|-----|
| **사이즈** | 16:9 (1920×1080px) |
| **포맷** | PPTX |
| **폰트** | `[한글 폰트 — 예: Pretendard]` / `[영문 폰트 — 예: Inter]` |
| **장수** | 15~25장 (사업 소개서 기준) |

---

## 2. 슬라이드 구조 (사업 소개서 기준)

### Section 1: 인트로 (1~3장)
1. **표지** - 제목 + 발표자 + 날짜
2. **목차** - 4~5개 섹션
3. **인사말** - 한 줄 인사 + `[브랜드 소개]`

### Section 2: 문제 정의 (4~7장)
4. **시장 현황** - "`[시장 트렌드 문장]`"
5. **고객 페인포인트** - Top 3~5
6. **기존 솔루션의 한계** - "`[경쟁사 한계]`"
7. **우리의 관점** - "`[차별화 메시지]`"

### Section 3: 솔루션 (8~14장)
8. **솔루션 한 줄 정의**
9. **핵심 차별점** - 3가지
10. **방법론 / 프레임워크** - 다이어그램
11. **사례 1**
12. **사례 2**
13. **성과 지표**
14. **고객 후기**

### Section 4: 제안 (15~20장)
15. **서비스 라인업**
16. **가격/패키지**
17. **진행 절차**
18. **FAQ**
19. **회사 소개 / Why Us**
20. **CTA + 연락처**

## 3. 슬라이드 레이아웃 패턴

### A. 표지 슬라이드
```
┌──────────────────────────────────┐
│                                  │
│  [로고]                          │
│                                  │
│                                  │
│  거대한 메인 타이틀                │
│  (한 줄, 64px Bold)               │
│                                  │
│  서브 타이틀 (24px Regular)        │
│                                  │
│                                  │
│  발표자명 · 날짜                  │
└──────────────────────────────────┘
```

### B. 본문 - 좌측 타이틀, 우측 콘텐츠
```
┌──────────────────────────────────┐
│ ┌──────┐ ┌──────────────────┐   │
│ │ 02   │ │                  │   │
│ │      │ │  본문 콘텐츠       │   │
│ │ H2   │ │  (도표/리스트)      │   │
│ │ 섹션 │ │                  │   │
│ │ 제목 │ │                  │   │
│ └──────┘ └──────────────────┘   │
└──────────────────────────────────┘
```

### C. 본문 - 3열 카드
```
┌──────────────────────────────────┐
│  섹션 타이틀                       │
│                                  │
│  ┌────┐  ┌────┐  ┌────┐         │
│  │ 01 │  │ 02 │  │ 03 │         │
│  │    │  │    │  │    │         │
│  │ 제목│  │ 제목│  │ 제목│         │
│  │ 설명│  │ 설명│  │ 설명│         │
│  └────┘  └────┘  └────┘         │
└──────────────────────────────────┘
```

### D. 다이어그램 슬라이드
```
┌──────────────────────────────────┐
│  방법론                            │
│                                  │
│   [1단계] → [2단계] → [3단계]      │
│                                  │
│   각 단계 설명 (작게)              │
└──────────────────────────────────┘
```

### E. CTA (마지막 슬라이드)
```
┌──────────────────────────────────┐
│                                  │
│         지금 시작하세요              │
│                                  │
│   📧 [contact@example.com]       │
│   🌐 [본인 채널/웹사이트 URL]      │
│                                  │
│         [브랜드명/로고]            │
└──────────────────────────────────┘
```

## 4. 폰트 사이즈 가이드

| 요소 | 사이즈 | 두께 |
|------|--------|------|
| 표지 메인 타이틀 | 80px | Bold |
| 표지 서브 타이틀 | 32px | Regular |
| 슬라이드 H1 | 48px | Bold |
| 슬라이드 H2 | 32px | SemiBold |
| 본문 | 20~24px | Regular |
| 캡션/주석 | 14~16px | Medium |

## 5. 컬러 시스템

> 💡 본인 브랜드 컬러는 `context/design-style-guide.md`에서 정의

- **배경**: `[메인 배경 컬러]` 통일 (일부 슬라이드만 반전)
- **본문 텍스트**: `[메인 텍스트 컬러 HEX]`
- **보조 텍스트**: `[보조 텍스트 컬러 HEX]`
- **강조/CTA**: `[포인트 컬러 HEX]`
- **그래프/차트**: 모노톤 + 포인트 컬러

---

## 6. 차트/도표 가이드

### 막대 그래프
- 단일 색상 (포인트 컬러)
- 그리드 라인 최소화
- 데이터 레이블은 막대 위에 표시

### 파이 차트
- 3~4개 카테고리까지만
- 모노톤 그라데이션 또는 단일 컬러 농도 변화

### 다이어그램
- 화살표는 가는 선 (1.5px)
- 박스는 둥근 모서리 8px
- 음영/그림자 최소화

---

## 7. 아이콘 사용

- **라이브러리**: `[예: Lucide Icons 또는 Heroicons (Outline 스타일)]`
- **사이즈**: 슬라이드 본문 24~32px
- **색상**: 본문 텍스트와 동일

---

## 8. 슬라이드 마스터 권장사항

PowerPoint/Keynote에서 슬라이드 마스터 설정 시:

1. **페이지 번호** - 우하단, 14px, 보조 텍스트 컬러
2. **로고** - 좌하단 또는 우상단 (작게)
3. **푸터** - "`[브랜드명]`" 또는 "`[@본인 채널]`"
4. **여백** - 상하좌우 80px
