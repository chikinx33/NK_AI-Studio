# 유튜브 썸네일 템플릿 (YouTube Thumbnail Template)

> 유튜브 채널 썸네일 디자인 가이드
> 디자인 원칙은 [[../context/design-style-guide]] 참조
> `[대괄호]` 안의 내용은 본인 브랜드에 맞게 교체하세요

---

## 1. 기본 사양

| 항목 | 값 |
|------|-----|
| **사이즈** | 1280×720px (16:9) |
| **포맷** | JPG 또는 PNG |
| **용량** | 2MB 이하 |
| **세이프존** | 가장자리 80px 내 핵심 정보 |

---

## 2. 썸네일 핵심 원칙

### Top 3 원칙
1. **모바일에서 텍스트가 읽혀야 한다** (작은 사이즈에서 가독성 확보)
2. **3초 안에 메시지 전달** (긴 카피 X)
3. **궁금증 > 답** (정답을 다 보여주지 않기)

### 본인 브랜드만의 차별점
> 💡 `context/design-style-guide.md`의 무드 키워드에 맞게 정의

- `[차별점 1 — 예: 정제된 느낌, 시끄러운 썸네일 지양]`
- `[차별점 2 — 예: 모노톤 + 한 가지 포인트 컬러]`
- `[차별점 3 — 예: 숫자/도발적 키워드 1개]`

## 3. 썸네일 레이아웃 패턴

### 패턴 A: 좌측 텍스트 + 우측 비주얼
```
┌───────────────────────────────────┐
│                  │                │
│  거대한          │                │
│  헤드라인         │  [이미지/      │
│  (3~4줄)          │   다이어그램]  │
│                  │                │
│  서브 카피        │                │
│                  │                │
│  [브랜드명]      │                │
└───────────────────────────────────┘
```

### 패턴 B: 중앙 정렬 (강조)
```
┌───────────────────────────────────┐
│                                   │
│                                   │
│        압도적 키워드               │
│        (120~160px Bold)            │
│                                   │
│        [+ 서브 카피]                │
│                                   │
│              [브랜드명]            │
└───────────────────────────────────┘
```

### 패턴 C: 숫자 강조형
```
┌───────────────────────────────────┐
│                                   │
│   [숫자]   ←← 거대한 숫자           │
│                                   │
│   [큰 카피]                        │
│   [큰 카피]                        │
│                                   │
│              [브랜드명]            │
└───────────────────────────────────┘
```

### 패턴 D: 화살표/비교형
```
┌───────────────────────────────────┐
│                                   │
│   [Before]   →   [After]          │
│   (회색)         (포인트 강조)      │
│                                   │
│   [부제 카피]                      │
│                                   │
└───────────────────────────────────┘
```

## 4. 텍스트 가이드

### 헤드라인 카피 길이
- **1줄 메인 카피**: 5~8자
- **2줄 카피**: 합계 12자 이내
- **3줄 카피**: 합계 18자 이내

### 카피 패턴 (효과 검증된 것)

| 패턴 | 예시 (본인 주제로 변형) |
|------|------------------------|
| **숫자 + 도발** | "`[~의 95%가 실패]`" |
| **반전** | "`[~잘 쓰면 안 됩니다]`" |
| **상위 X%** | "`[상위 1%만 아는 이것]`" |
| **VS 비교** | "`[A vs B]`" |
| **부정 후킹** | "`[이거 모르면 ~ 못 합니다]`" |

## 5. 폰트 & 사이즈

| 요소 | 사이즈 | 두께 |
|------|--------|------|
| 메인 헤드라인 | 120~160px | Black (900) |
| 서브 카피 | 48~64px | SemiBold (600) |
| 숫자 강조 | 280~320px | Black (900) |
| 로고/채널명 | 32~40px | Medium (500) |

**필수 폰트**: `[본인 한글 폰트 — 예: Pretendard]`

## 6. 컬러 시스템

> 💡 본인 브랜드 컬러는 `context/design-style-guide.md`에서 정의

### 배경
- **밝은 버전**: `[메인 배경 컬러 HEX]` 또는 흰색
- **어두운 버전**: `[다크 배경 컬러 HEX]` 또는 검정

### 텍스트
- **메인**: 배경과 반대 (밝은 배경 → 어두운 텍스트 / 어두운 배경 → 밝은 텍스트)
- **강조 키워드**: `[포인트 컬러 HEX]`
- **부정/경고**: `[경고 컬러 HEX]` - 자제하여 사용

### 컬러 사용 비율
- 무채색 (검정/흰/회색) **85%**
- 포인트 컬러 **15% 이하**

---

## 7. 비주얼 요소

### 사용 권장 ✅
- 단순 도형 (사각형, 원, 화살표)
- 다이어그램 (Before → After)
- 데이터 시각화 (그래프, 차트)
- 흑백 사진 + 듀오톤 처리
- 굵은 밑줄/하이라이트

### 사용 지양 ❌
- 화려한 그라데이션
- 만화/이모지 과다
- 풍선/말풍선
- 무지개색 텍스트
- `[본인 브랜드 톤에 안 맞는 요소 추가]`

---

## 8. 시리즈 일관성

### 시리즈물 통일 요소
1. **번호 표기** 일관 위치 (예: 좌상단 "#01")
2. **카테고리 태그** 같은 색상/위치
3. **로고 위치** 고정 (우하단 또는 좌하단)
4. **배경 컬러** 동일

## 9. AI 이미지 생성 시 프롬프트

Nano Banana(Gemini) MCP 활용 예시:

```
A YouTube thumbnail for [본인 채널 카테고리 — 예: Korean AI tech channel "[브랜드명]"],
1280x720 16:9 aspect ratio,
title text: "[제목]",
huge [한글 폰트 — 예: Pretendard] Korean typography (Bold 120px+),
[배경 — 예: white or black background],
single accent color [본인 포인트 컬러 HEX],
minimal design, [브랜드 무드 키워드],
no clutter, no gradient, no cartoon,
small "[브랜드명]" logo at bottom right,
high contrast, mobile-readable
```

## 10. A/B 테스트 권장사항

같은 영상에 대해 **2~3가지 썸네일 변형** 만들고 비교:

| 변형 | 차이 |
|------|------|
| A | 텍스트 중심 |
| B | 숫자 강조 |
| C | 화살표/비교형 |

## 11. 체크리스트

- [ ] 1280×720 해상도인가?
- [ ] 모바일(120×67)에서도 텍스트가 읽히나?
- [ ] 채널 로고가 들어가 있나?
- [ ] 컬러가 3가지 이내인가?
- [ ] 폰트가 디자인 가이드와 일치하나?
- [ ] 같은 시리즈 다른 영상과 통일감 있나?
- [ ] 카피가 너무 길지 않나? (헤드라인 18자 이내)
