# 카드뉴스 템플릿 (Card News Template)

> 인스타그램/링크드인 카드뉴스 디자인 가이드
> 디자인 원칙은 [[../context/design-style-guide]] 참조
> `[대괄호]` 안의 내용은 본인 브랜드에 맞게 교체하세요

---

## 1. 기본 사양

| 항목 | 값 |
|------|-----|
| **사이즈** | 1080×1080px (정사각) / 1080×1350px (포트레이트) |
| **포맷** | PNG (투명배경 X) / JPG |
| **장수** | 5~8장 권장 |
| **여백** | 가장자리 80px 안전 마진 |

---

## 2. 슬라이드 구성 공식

### 표지 (1장)
**역할**: 후킹 + 클릭 유도

```
┌────────────────────────────┐
│  [카테고리 태그 (작게)]      │  ← 예: #[본인 카테고리]
│                            │
│                            │
│  큰 헤드라인               │  ← 80~120px Bold
│  (2~3줄, 강한 임팩트)        │
│                            │
│                            │
│                            │
│         [브랜드명/로고]      │  ← 로고 (작게)
└────────────────────────────┘
```

**카피 예시 패턴** (본인 브랜드 톤에 맞게 교체):
- "`[의문형 후킹 — 예: ~만으론 부족하다]`"
- "`[상위 X% 후킹 — 예: 상위 1%만 아는 ~]`"
- "`[반전 후킹 — 예: ~의 진짜 이유]`"

---

### 문제 제기 (2장)
**역할**: 시청자의 페인포인트 자극

```
┌────────────────────────────┐
│  02 / 06                   │
│                            │
│  혹시 이런 경험 있으세요?   │  ← H2
│                            │
│  □ [페인포인트 1]           │  ← 체크리스트 형식
│  □ [페인포인트 2]           │
│  □ [페인포인트 3]           │
│                            │
└────────────────────────────┘
```

> 💡 페인포인트는 `context/business-context.md`의 Top 5 페인포인트에서 가져옵니다.

---

### 핵심 메시지 (3장)
**역할**: 정답/통찰 제시

```
┌────────────────────────────┐
│  03 / 06                   │
│                            │
│  [도입 카피]               │
│  [예: "답은 ~가" → 굵게]    │
│                            │
│  → [핵심 메시지]            │  ← 포인트 컬러로 강조
│                            │
└────────────────────────────┘
```

---

### 설명/근거 (4~5장)
**역할**: 왜 그런지 풀어주기

- **비유 1개 + 예시 1개** 권장
- 다이어그램이나 도식 활용 가능
- 한 슬라이드 한 개념

---

### 적용법 (6장)
**역할**: 시청자가 바로 할 수 있는 행동 제시

```
┌────────────────────────────┐
│  지금 바로 해볼 것           │
│                            │
│  1️⃣ [행동 1]               │
│  2️⃣ [행동 2]               │
│  3️⃣ [행동 3]               │
│                            │
└────────────────────────────┘
```

---

### CTA (7장, 마지막)
**역할**: 다음 행동 유도

```
┌────────────────────────────┐
│                            │
│  더 깊이 알고 싶다면?        │
│                            │
│  ▶ [CTA 1 — 예: 유튜브 풀영상] │
│  ▶ [CTA 2 — 예: 구독 알림]   │
│                            │
│  [@본인 채널 핸들]           │
└────────────────────────────┘
```

## 3. 텍스트 길이 규칙

| 슬라이드 | 헤드라인 | 본문 |
|---------|---------|------|
| 표지 | 12자 이내 | - |
| 본문 | 15자 이내 | 슬라이드당 50자 이내 |
| CTA | 10자 이내 | 항목당 10자 이내 |

## 5. AI 이미지 생성 시 프롬프트 템플릿

Nano Banana(Gemini) MCP로 카드뉴스 생성 시:

```
A [디자인 스타일 키워드] card news design for [본인 채널 카테고리],
[슬라이드 주제 한 줄],
1080x1080 square,
[배경 컬러 — 예: white background],
single accent color ([본인 메인 컬러 HEX]),
large [한글 폰트명] Korean typography,
lots of whitespace (70%+),
[브랜드 무드 키워드],
no clutter, no gradient,
slide number at top: [숫자 / 총장수]
```

> 💡 본인 디자인 가이드 (`context/design-style-guide.md`)의 "AI 이미지 생성 프롬프트 가이드" 섹션 참조

## 6. 체크리스트 (배포 전 확인)

- [ ] 표지의 후킹이 강한가?
- [ ] 슬라이드당 메시지 1개만 있나?
- [ ] 폰트가 디자인 가이드를 따르나?
- [ ] 컬러가 3가지 이내인가?
- [ ] 마지막 슬라이드에 CTA가 있나?
- [ ] 브랜드 로고가 모든 슬라이드에 있나?
- [ ] 슬라이드 번호 표기가 일관된가?
